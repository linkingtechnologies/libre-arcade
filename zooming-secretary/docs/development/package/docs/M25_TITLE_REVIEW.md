# M25 — Archival title / naming review

Date: 2026-10-12

## Decision

**PROJECT NAMING GATE: ACCEPTED for archival/descriptive use.**

The public metadata uses the qualified form **“Zooming Secretary — Libre Arcade Restoration”**.
The game screen keeps the historical title as plain text. No historical logo, cartridge-label art,
trade dress or publisher branding is reused. Credits state that this is an **unofficial** restoration
and that no endorsement by the original authors or later port teams is implied.

This is a project release decision, **not a formal trademark clearance or legal opinion**.

## Current-web review

A targeted public-web check on 2026-10-12 found:

- Shiru's current software page still lists **Zooming Secretary** as an original collaboration with
  PinWizz and links the source/release.
- The Uzebox project uses the same historical title for its port.
- A current Mega Drive/Genesis port page uses **Zooming Secretary (SMD)** and identifies the NES
  game by PinWizz and Shiru as the original.
- A ZX Spectrum port continues to use the same title commercially and explicitly attributes the
  original 2011 idea to PinWizz and Shiru.
- RGCD, MobyGames and speedrun/catalog pages also continue to use the title as the historical game
  identifier.

Targeted exact-title searches aimed at public EU/UK/US trademark web surfaces did not surface an
exact registration in the search results available to this audit. That absence is **not** treated as
proof that no registration exists.

## Release convention

M25 therefore adopts these naming safeguards:

1. use `Zooming Secretary` only to identify the historical work being restored;
2. qualify document/page metadata as **Libre Arcade Restoration**;
3. use a new text treatment only — no original logo/trade dress;
4. keep original-author attribution in Credits;
5. state non-affiliation / no endorsement;
6. make no trademark ownership claim.
