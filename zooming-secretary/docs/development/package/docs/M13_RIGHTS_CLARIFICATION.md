# Rights clarification — optional questions for the original authors

M13 does not require outreach to begin implementation, but any future reply can simplify the preservation route. Useful points to clarify:

1. Which exact Creative Commons Attribution version was intended for Zooming Secretary v1.02 in December 2011?
2. Did that grant cover game-specific source code, level/map data, graphics, music/SFX and manual/labels equally, or were any components excluded?
3. Would Shiru be willing to relicense the original Zooming Secretary music under CC0, CC BY 4.0, or GPLv3-compatible terms?
4. Would PinWizz be willing to relicense the original graphics/visual design and fact messages under CC0 or CC BY 4.0?
5. May Libre Arcade redistribute the exact semantic level geometry with attribution?

Any answer must be preserved verbatim with date/source and must identify which rights holder is granting rights to which component.
