# Reference policy — Zooming Secretary

This public `reference/` directory is **metadata-only**.

The archaeology workspace may contain private/local copies of the historical ROM, release ZIP, manual, labels and recovered source solely for provenance, build reconstruction and differential testing. Those bytes are **not automatically redistributable project assets** and must not be copied into the Libre Arcade distributable repository.

Public reference material is limited to checksums, source locations, version/date metadata, behavioral oracle documentation and licence findings.
