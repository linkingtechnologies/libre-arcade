# Quarantined historical media

These files are preserved from release 0.97.8 but are not loaded by the browser runtime.

- `fonts/`: bitmap font sheets; underlying typeface/source provenance is undocumented.
- `music/menu.xm`: package-licensed and composer-credited, but embedded MID2XM/General-MIDI-style sample provenance is undocumented.

The historical WAV effects were promoted to `/assets/audio` for 1.0 after the separate audio audit. Their original copies remain, unchanged, in `/reference`.

See `docs/ASSET_AUDIT.md` and `docs/AUDIO_AUDIT.md`.
