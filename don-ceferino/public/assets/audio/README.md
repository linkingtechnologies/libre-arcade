# Historical sound effects

These WAV files are byte-identical copies of the files loaded by `src/audio.cc` in Don Ceferino Hazaña 0.97.8.

The original `data/sounds/LICENSE-KIND.FILES` is copied here unchanged and grants GPL version 2 or later for this data directory. The browser port uses the same one-channel behavior as SDL_mixer: starting a new effect interrupts the previous effect.

`explo.wav` is preserved only under `/reference` and `/quarantine` because the 0.97.8 audio loader does not load it.
