# Changelog

## 1.0.0

First release in Libre Arcade: Raging Gardens (Petar Petrov, GitHub Game Off 2012), restored as plain HTML5 canvas and vanilla
JavaScript with no library and no server. The game logic is a port of the original (head `25ee169`, whose gameplay is that of
the Game Off submission and of the Facebook fork) and reproduces it on every frame of 19 recorded three-minute games run on
the original under Crafty 0.6.3. The original artwork (all rights reserved) and sound effects (licences unverifiable) are not
used: the pictures are drawn by the code, the effects are synthesised, the music is the CC0 original. English and Italian,
touch controls, pause, restart, a publication gate that fails closed. See `PROVENANCE.md`, `specs/port-map.md` and `docs/`.
