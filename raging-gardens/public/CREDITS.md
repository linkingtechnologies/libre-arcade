# Credits

**Raging Gardens** was made by **Petar Petrov** (game design and programming) for the GitHub Game Off 2012,
where it received an honorable mention. Its artwork was made by **Stremena Tuzsuzova**, whose work is not
included in this version (all rights reserved).

- Music: "Trouble in the Garden" by Augmentality (Brandon Morris), via OpenGameArt, CC0.
- Path finding: javascript-astar by Brian Grinstead (MIT), binary heap by Marijn Haverbeke (CC BY 3.0).
- Original sound effects: edited clips from Freesound, not included; see THIRD_PARTY_NOTICES.md.
- Original engine: CraftyJS by Louis Stowasser, with jQuery, Backbone.js, Underscore.js, RequireJS and Modernizr; none is needed here.
- This restoration, the new pictures, the synthesised sounds, the interface and the tests: Umberto Bresciani, for [Libre Arcade](https://github.com/linkingtechnologies/libre-arcade) (source code and the rest of the collection), GPL-3.0-or-later.

Full licence texts and the file-by-file inventory: THIRD_PARTY_NOTICES.md and assets/PROVENANCE.json.
