# Historical reference material

This directory documents the preserved Donkey Bolonkey upstream snapshot used for archaeology and parity work.

- `dkbk/` contains the redistributable textual/code portion of the unpacked historical source tree. Binary historical media and screenshots are intentionally omitted from the public repo-safe package.
- `SHA256SUMS` records the exact hashes of the historical upstream tarball and Allegro `dkbk.dat` datafile.
- `archive/donkey-bolonkey_2001.orig.tar.gz` and `dkbk/dkbk.dat` are retained in the full laboratory package but are excluded from the public repo-safe package because the datafile contains media with unclear or non-free provenance.

The web runtime never loads files from this directory.
