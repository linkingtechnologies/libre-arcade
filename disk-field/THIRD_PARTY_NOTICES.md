# Third-party / historical asset notices

The public HTML5 game does not redistribute the historical Disk Field font or audio recordings.

The separate private archaeology bundle retains the untouched 1.0 and 1.01 archives under `reference/` for preservation and verification. Those archives contain historical assets whose redistribution status is not uniformly established.

## Historical font

`MAKISUPA.TTF` (R. Gast / DarkSide Productions) is present only inside the preserved upstream archive. The license text shipped with Disk Field places additional conditions on redistribution as part of software/collections, including written permission. It is therefore not used by the public port.

Replacement: no font file. M5 draws its main arcade lettering procedurally in Canvas and uses the host system UI font for ordinary controls/credits.

## Historical audio

The preserved 1.01 archive contains `tradeyourkid.ogg`, five attributed WAV samples, and three `thud*.ogg` collision sounds. The archive does not provide sufficiently verified per-file redistribution terms for the complete set, so none is shipped by the public port.

Replacement: original procedural Web Audio effects and music generated by the M5 port code. These replacements do not sample, embed, or reproduce the historical recordings.

## Original source excerpts and historical research records

`tools/oracle_compat/v1.01/lib/` contains seven historical Python implementation modules needed for headless comparison. They are not byte-identical to the archive: five hash to the archive's values once LF line endings are converted back to CRLF, and two (`DfLevelData.py`, `DfObjects.py`) carry small further compatibility adaptations that cannot be itemized without the private archive (see `PROVENANCE.md`). `archaeology/stratigraphy/stratigraphy-v1.0-v1.01.patch` and `archaeology/upstream-text/` preserve original source/text excerpts and documentation for research. These are **historical upstream material**, not newly authored GPLv3 port source.

The upstream README's original license wording is: “Do whatever you like. Would like it if you gave me some sort of credit.” It is a custom informal permissive grant rather than an SPDX-standard license. Credit to Jeremy Appleyard (Tigga), PyWeek 5 (2007). The separate project GPLv3 license covers new port code, not a retroactive relicensing of these upstream excerpts. Asset-specific notices and unresolved permissions are documented in `archaeology/inventories/asset-license-audit.csv`.

`reference/upstream-index.csv` and `archaeology/inventories/manifest.json` document the private original archives and file hashes **without** distributing the audio, font, icons or full asset-containing original archives.
