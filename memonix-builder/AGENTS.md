- `tests/release.test.mjs` and `tests/production.test.mjs` originally computed their root directory with `path.resolve(new URL('..',import.meta.url).pathname)`, which doubles the drive letter on Windows (`C:\C:\Users\...`) because a `file://` URL's `pathname` keeps its leading slash before the drive letter. Both were fixed to use `fileURLToPath(new URL('..',import.meta.url))`, matching the pattern every other test file in this game already used. If a future edit reintroduces the `.pathname` idiom anywhere in this game's tests, it will silently pass on POSIX CI and fail on Windows — use `fileURLToPath`.
- Tests live in `tests/*.test.mjs` (matching how the package was delivered, distinct from `memonix-mosaic/`'s `tests/*.mjs`); `npm test` runs `node --test tests/*.test.mjs`. Every test file resolves game assets under `public/` and non-game files (`reference/`, `docs/`, `LICENSE`, etc.) at the game root — keep that split when adding tests.
