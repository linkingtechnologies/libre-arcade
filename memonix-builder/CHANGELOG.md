# Changelog

## Unreleased

- Initial Libre Arcade release: a standalone HTML5 restoration of Builder, one of the four suite modes in Michael Kurinnoy / Viewizard Games' Memonix 1.6 (2006).
- Restructured the delivered package to this collection's `public/`/`game/` contract: `index.html`, `css/`, `src/` and `assets/` moved into a new `public/` folder, with `reference/`, `docs/`, `tests/`, `LICENSE` and the other project files staying at the game root. Added the collection's scaffolding: `package.json` scripts (`dev`, `build`, `start`, `test`, `lint`, `check`), `scripts/serve.mjs`, `scripts/build.mjs`, an ESLint config, `.gitignore`, the GoatCounter snippet and a "Play here" link.
- Confirmed the license is **GPL-3.0-only**, the same finding as this collection's Memonix: Mosaic: the recovered `Memonix-License.txt` and every per-file C++ header name GPL version 3 with no "or later" clause. `LICENSE`, `package.json` and `PROVENANCE.md` all reflect this.
- Independently re-verified every redistributed asset from first principles, reusing the VFS/RLE/BMP/PNG pipeline built for Memonix: Mosaic: re-ran it against this package's own copy of `gamedata.vfs` (confirmed byte-identical to Mosaic's) and found all 265 archive entries decompress cleanly, all 88 recovered Builder component bitmaps are pixel-identical to the distributed PNGs, and all other UI conversions (colour-keyed overlays and lossless sprite sheets) match exactly. Went further than the Mosaic check on gameplay logic: read all 19 cases of the original structural-code generation `switch` in `game_start.cpp` line-by-line against the port, and diffed all 704 cells of the 11 house templates programmatically — zero mismatches, and one subtle, correctly-preserved source quirk confirmed (case `403`'s narrower difficulty-1 cache range, unlike its two sibling cases). Recorded in `PROVENANCE.md`, `specs/port-map.md` and `SOFTWARE_ARCHAEOLOGY.md`.
- Fixed a Windows-only path bug in two delivered test files (`tests/release.test.mjs`, `tests/production.test.mjs`): both computed their root directory with `path.resolve(new URL('..',import.meta.url).pathname)`, which doubles the drive letter on Windows because a `file://` URL's `pathname` keeps the leading slash before the drive letter. Switched both to `fileURLToPath(new URL('..',import.meta.url))`, matching every other test file in this game.
- Fixed an Options-screen layout bug in this restoration's own new UI code (not recovered original behavior): the "Preview countdown"/"Tempo di memorizzazione" label overlapped the On/Off toggle because the available space was too narrow for the longer Italian translation (measured with `ctx.measureText`: 220.7px needed, 175px available). Shifted the On/Off/minus/plus control group right by 75px to give the label room.
- Fixed an Instructions-screen layout bug in both languages: the five help paragraphs were drawn with a fixed 70px step per paragraph regardless of how many lines each one actually wrapped to, so the longer paragraphs ran under the Back button (confirmed with `ctx.measureText`: the real text block needs up to 515px of height — or 526px for Italian, whose fifth paragraph wraps to 4 lines instead of English's 3 — against 337px available before the button). `wrapText` now returns the cursor position after the last line it drew, and `drawInstructions` uses that to place each paragraph immediately after the previous one; line height and the inter-paragraph gap were also tightened (25px/14px → 21px/8px) to fit the longest-wrapping language with a safe margin instead of just barely fitting one of the two.
- Raised the procedural click/error/win tone volume (0.035 peak gain for every kind → 0.09 for click/win, 0.12 for error, with a longer decay), confirmed to be technically working (no exception, `AudioContext` reaches `running`) but too quiet to notice on typical speakers, same fix already applied to Memonix: Mosaic.
- No change to gameplay rules, board geometry, difficulty behavior, structural templates, piece probabilities, the Ltr/Rtr drainpipe dependencies, the four historical title-screen window coordinates, or any redistributed asset.
