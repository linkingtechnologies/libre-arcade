## Timeline

- 2001-11-16 — source archive version date and release identifier.
- 2001-11-22 — FreeBSD port added, only days after the release.
- 2001-12-05 — SDL news lists 54321 among newly added SDL games.
- Late 2001 — 54321 appears in the SDL 1 MB Game Programming Contest results with 396.1 points; its Noweb source documentation is specifically praised.
- 2009 — a PLD source RPM mirror still carries version 1.0.2001.11.16.
- 2014 onward — later platform preservation ports appear, including AROS/MorphOS-era packages.
- 2026-05 — Dave Yeo publishes an OS/2 port based on the historic source.
- 2026-08 — Martin Iturbide updates the OS/2 port to SDL2.

No evidence was found of a later upstream gameplay release by Patrick Stein. The modern activity is best classified as preservation/porting rather than resumed upstream development.
