# Software archaeology dossier

This directory contains the detailed archaeology record behind the browser restoration.

- `HISTORY.md` — author, release chronology, mirrors, downstream preservation activity.
- `GAMEPLAY.md` — the five advertised games plus the hidden Life easter egg.
- `TECHNICAL_NOTES.md` — SDL/Noweb architecture, logical 2D/3D/4D model, data formats, input, audio.
- `PRESERVATION_POLICY.md` — preserved vs faithful port vs reconstructed/enhanced material.
- `LEGAL_STATUS.md` — conservative licensing/provenance record and why the repository has no blanket GPLv3 declaration.

The complete untouched historical tree and exact uploaded archive live under `/reference`.
