# Changelog

## 1.0.0 — 2026-09-06

- Added Grugnetto Go! to this collection: a platformer built from scratch
  (melonJS + lit-html), not a restoration. `public/` is fully self-contained
  — see [`public/specs/design.md`](public/specs/design.md) and
  [`public/specs/use-case.md`](public/specs/use-case.md) for its design.
- Added dependency-free dev tooling (`npm run dev`/`build`/`start`/`test`/`lint`/`check`)
  so the game runs on any static web server with no framework or hosting
  platform required.
