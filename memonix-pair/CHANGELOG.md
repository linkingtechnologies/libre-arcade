# Changelog

## 1.0.0

- Initial Libre Arcade release: a standalone HTML5 restoration of Pair, one of the four suite modes in Michael Kurinnoy / Viewizard Games' Memonix 1.6 (2006), sharing a title screen, archive and license with this collection's Memonix: Mosaic and Memonix: Builder.
- Restructured the delivered package to this collection's `public/`/`game/` contract: `index.html`, `css/`, `src/` and `assets/` moved into a new `public/` folder, with `reference/`, `docs/`, `tests/`, `LICENSE` and the other project files staying at the game root. Added the collection's scaffolding: `package.json` scripts (`dev`, `build`, `start`, `test`, `lint`, `check`), `scripts/serve.mjs`, `scripts/build.mjs`, an ESLint config, `.gitignore`, the GoatCounter snippet and a "Play here" link.
- Confirmed the license is **GPL-3.0-only**, the same finding as this collection's Memonix: Mosaic and Memonix: Builder: the recovered `Memonix-License.txt` and every per-file C++ header name GPL version 3 with no "or later" clause.
- Independently re-verified every redistributed asset, reusing the VFS/RLE/BMP/PNG pipeline already built and verified for Memonix: Builder — no re-extraction was needed, since this package's `gamedata.vfs` is byte-identical to the one already pulled apart. All 72 Pair card assets (card back plus 71 toy faces) are pixel-identical to their recovered BMP source, the three UI conversions match exactly, and the shared `blank-cell.png` was confirmed to be a byte-for-byte copy of Builder's own blank tile rather than a separately-sourced lookalike. Also confirmed, independently of the delivered documentation, by reading `game_start.cpp` and `game.cpp` directly: the 71-face pool with its historical `toys-015` gap, the reject-and-retry (not Fisher-Yates) placement algorithm, and the Hard-difficulty mechanic that restores the entire board, including already-completed pairs, after any single mismatch. Recorded in `PROVENANCE.md`, `specs/port-map.md` and `SOFTWARE_ARCHAEOLOGY.md`.
- Fixed a Windows-only path bug in `tests/production.test.mjs`, the same bug already found and fixed in Memonix: Builder: it computed its root directory with `path.resolve(new URL('..',import.meta.url).pathname)`, which doubles the drive letter on Windows. Switched to `fileURLToPath(new URL('..',import.meta.url))`, matching this game's own `tests/release.test.mjs`, which already used the correct pattern as delivered.
- Fixed an Options-screen layout bug in this restoration's own new UI code (not recovered original behavior): the "Preview countdown"/"Tempo di memorizzazione" label overlapped the On/Off toggle because the available space (160px) was too narrow for the longer Italian translation (209px, measured with `ctx.measureText`). Shrank the minus/value/plus controls slightly, shifted the whole control group right, and reduced the label's font size (18px → 16px) to fit the longest-wrapping language with a safe margin.
- Raised the procedural click/error/win tone volume (0.035 peak gain for every kind → 0.09 for click/win, 0.12 for error, with a longer decay), the same fix already applied to Memonix: Mosaic and Memonix: Builder: confirmed to be technically working (no exception, `AudioContext` reaches `running`) but too quiet to notice on typical speakers.
- No change to gameplay rules, deck generation, difficulty behavior, the match/mismatch timing, the Hard-mode full-board restore, the four historical title-screen window coordinates, or any redistributed asset.
