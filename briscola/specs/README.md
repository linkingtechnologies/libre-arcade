# BriscoLab specifications

This folder contains the stable technical contracts of BriscoLab. These files
are normative for project structure and integration work; the root README is an
overview and `CHANGELOG.md` is historical documentation.

- [`architecture.md`](architecture.md) — layer boundaries and dependency rules.
- [`game-engine.md`](game-engine.md) — engine responsibilities and lifecycle.
- [`card-model.md`](card-model.md) — canonical card representation and ranking.
- [`player-interface.md`](player-interface.md) — common player/action API.
- [`player-observation.md`](player-observation.md) — legal information boundary.
- [`adapter-guidelines.md`](adapter-guidelines.md) — upstream-to-engine mapping.
- [`faithful-porting.md`](faithful-porting.md) — preservation and oracle policy.
- [`arena-benchmark.md`](arena-benchmark.md) — simulation and result contract.
- [`reference-sources.md`](reference-sources.md) — preserved source policy.
- [`players.md`](players.md) — integrated player catalog.
