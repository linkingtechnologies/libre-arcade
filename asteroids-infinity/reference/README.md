# Historical reference

`AsteroidsInfinity-1.2.py` is the byte-identical Python source file extracted from the original user-supplied SourceForge Asteroids Infinity 1.2 archive. It has not been modified. Original archive SHA-256: `b0adc1fe656722e23142b9ee6a3cf51b2b3c743827e45356a50d4580dfbc2b20`.

Original author Ben Whittaker, (C) 2009; GPL version 3 or later, as printed in the file header. The complete original ZIP, original font and historical audio assets remain in the **separate private M0.x audit bundle** and are not part of this HTML5 prototype. M2's diagnostics extract and execute limited original Python methods under Python 3, not an original full Python 2/Pygame game.
