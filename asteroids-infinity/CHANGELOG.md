# Changelog

## Unreleased

- First public version, joined to the Libre Arcade collection. The delivered package had an empty changelog and kept the page at its own root.
- Moved the page to `public/` (`index.html`, `style.css`, `src/`) as the collection layout requires, and repointed the tests at it, 12 Node files and 14 of the 15 Python files (path changes only). The 113 Node tests pass unchanged; `test/test_http_assets_m10.py` passes; the Playwright browser tests were not run (Playwright is not installed here).
- Added `package.json` with the collection's scripts (`dev`, `build`, `start`, `test`, `lint`, `check`), `scripts/serve.mjs`, `scripts/build.mjs`, an ESLint config, a `.gitignore` covering `/game/` and `.claude/`, the GoatCounter snippet in `public/index.html` and a "Play here" link in `README.md`. The README no longer says the page has no third-party scripts: it now carries the collection's snippet, and `THIRD_PARTY_NOTICES.md` says so.
- Re-ran both executable oracles. `test/make_oracle_asteroids_m2.py` regenerated `test/oracle-asteroids-m2.json` byte for byte identically (SHA-256 `8a1fe2e9…`), and `test/original_file_oracle_m7.py` round-tripped the original `controls.txt` and `highscores.txt` through the JavaScript parser.
- Fixed two portability faults in the delivered Python tests, with no assertion changed: `Path.read_text()` was called without an encoding (50 call sites), which fails on a cp1252 Windows console because `src/app.js` contains U+2190; and `original_file_oracle_m7.py` now pins LF on write, because Python's text mode had been turning the historical files into CRLF and the oracle compares bytes.
- Removed a duplicated `savedLocal` key from the string tables in `public/src/app.js`. It appeared twice inside the same object literal in both languages, with the same text each time, so nothing changed on screen. Also removed seven dead locals from the test files, flagged by the new lint step.
- Added `PROVENANCE.md`, `specs/port-map.md`, `SOFTWARE_ARCHAEOLOGY.md`, `STORY.md`, `AGENTS.md` and a screenshot for the arcade index. Verified the licence directly in the header of `reference/AsteroidsInfinity-1.2.py` (GPL version 3 or later) and checked the SourceForge project page, which states the shorter "GPLv3".
- Condensed `specs/` from 46 files (309 KB) to four. The ten milestone reports, nine test records and three release gates became `specs/AUDIT.md`, one document with a section per milestone; `M12_USER_ACCEPTANCE.md` was kept unchanged as `ACCEPTANCE.md`; one copy of the file-oracle output was kept as `ORIGINAL_FILE_ORACLE.log`. Dropped: 22 runner logs, either reproducible with `npm run check` or snapshots of code that no longer exists, five of them byte-identical duplicates of another log, plus `FILES_SHA256.txt`, which listed the package before the move to `public/` and is superseded by `SHA256SUMS.txt`. `AUDIT.md` lists what went and why. Nothing was lost from the project's history: the folder had never been committed, and the delivered archive holds the full set.
- Regenerated `SHA256SUMS.txt` over the files that now ship, in the delivered format.
- No change to the game logic, the interface, the strings, the sounds or the preserved reference file.
