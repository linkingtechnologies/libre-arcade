# AGENTS.md

- License: GPL-3.0-or-later, from the header of `reference/AsteroidsInfinity-1.2.py`, not from the SourceForge page (which says only "GPLv3"). `PROVENANCE.md` records that distinction; do not restate the licence from the project page.
- `reference/AsteroidsInfinity-1.2.py` is preserved evidence, byte-identical, LF endings, listed in `SHA256SUMS.txt`. Never edit, reformat or repack it. The original ZIP, the Vector Battle font and the WAV effects are deliberately absent: their redistribution rights were never established. Do not add them, and do not present the synthesized Web Audio cues in `public/src/sound.js` as a reconstruction of the original sounds.
- Historical behavior and documented adaptations stay separate. Bugs of the original are kept on purpose: the degenerate `uniform(-2π, -2π)` asteroid spin (original line 284, still consuming its RNG draw), the single wrap per axis in `Obj.update`, and scoring that ignores kills the player did not cause. Never "fix" one without changing `specs/port-map.md` and the oracle fixtures, and never describe an adaptation (frame clock, audio, touch controls, Italian strings, browser storage) as original behavior.
- The oracles are runnable and must stay so. `test/make_oracle_asteroids_m2.py` regenerates `test/oracle-asteroids-m2.json` from the preserved source; it is expected to reproduce the file byte for byte. `test/original_file_oracle_m7.py` runs the original `controls.txt` and `highscores.txt` routines and round-trips them through `public/src/native-files.js`; it pins LF on write, because the comparison is a byte comparison. Both need only Python 3 and Node.
- `test/browser_smoke_m*.py` and `test/browser_full_session_m10.py` need Playwright and Chromium and inline the modules by hand; they do not certify an ordinary HTTP load. `test/test_http_assets_m10.py` needs only Python and does check the served page.
- `test/test-m12.mjs` asserts that the initial HTML carries no Libre Arcade branding or link: the collection is credited from the Credits screen only. Keep it that way. The one remote reference in `public/` is the GoatCounter snippet.
- No frameworks, no bundler, no backend. `public/` is the game, plain ES modules, served as is.
- `specs/` holds four files and should stay that size: `AUDIT.md` (the twelve milestones of the port, condensed from the 42 delivered reports, logs and gates), `port-map.md`, `ACCEPTANCE.md` and one oracle log. Do not reintroduce per-milestone files or commit raw test-runner output; record an outcome in `AUDIT.md` instead.
- `npm run check` (ESLint plus 113 Node tests) must pass before packaging, and `SHA256SUMS.txt` must be regenerated when any packaged file changes.
