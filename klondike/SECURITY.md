# Security policy

## Supported version

Security fixes are provided for the latest published release of Grugnetto’s Klondike.

## Reporting a vulnerability

Please report security issues privately through the contact channel published at <https://www.grugnett.org/>. Do not include credentials, personal information or exploit details in a public issue.

The game runs entirely in the browser, uses no analytics or advertising services, and stores game progress and preferences only in local browser storage. Clearing local data from the in-game menu removes those records from the current browser profile.
