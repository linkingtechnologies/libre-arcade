# Certification reports / Rapporti di certificazione

Run `npm run certify:random` to regenerate `random-deals-latest.json`. The report separates solved and cross-certified deals from bounded `unknown` results.

Eseguire `npm run certify:random` per rigenerare `random-deals-latest.json`. Il rapporto separa le partite risolte e certificate sui due motori dai risultati limitati `unknown`.
