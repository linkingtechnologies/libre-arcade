# Original KludgopolB provenance

Recovered official SourceForge release set (2012-12-24):

- `KludgopolB_src.zip` — original Java source archive. Audited; **not redistributed in the public package**. Exact SHA-256 and upstream location are recorded in `EXTERNAL_ARTIFACTS.md`.
- `KludgopolB.zip` — original runnable distribution (`KludgopolB.jar`, board data, rule presets and runtime assets). Audited; **not redistributed in the public package**. Exact SHA-256 and upstream location are recorded in `EXTERNAL_ARTIFACTS.md`.
- `changelog.txt` — upstream changelog. Preserved byte-for-byte in this public package.

Only locally redistributed historical files are listed in `SHA256SUMS`. External audited artifacts are tracked separately in `EXTERNAL_ARTIFACTS.md`.

Upstream project:

- https://sourceforge.net/projects/kludgopolb/
- https://sourceforge.net/projects/kludgopolb/files/

SourceForge project metadata identifies the project as Beta and declares BSD License + GNU GPLv3. The recovered archives themselves do not contain a licence text, so that discrepancy is recorded rather than silently resolved.

The original runtime contains UK/US board definitions and card stacks described upstream as regional commercial property-trading variants. Those materials are not used by the playable Grugnetto board and are deliberately excluded from this distributable package. The source archive is also externalized because it embeds original PNG artwork and does not document licence scope internally. This is a conservative redistribution policy, not a claim about the ultimate legal status of the upstream files.
