# Grugnetto's KludgopolB

Software-archaeology restoration of the abandoned Java property-trading game **KludgopolB**, preserving its configurable engine concepts and seven historical CPU personalities, plus the clean behavioural reimplementation **Pazifik**. The recovered regional board content is not used by the browser game: play takes place on the original Grugnetto board and the `grugnetto-islands` illustrated presentation layout.

The game is a work in progress and is not yet linked from the arcade index.

## The game

A static, client-side browser game built on the production `GameController`: one human player against 1–7 CPU friends, with dice, acquisitions, auctions, pledging places and embellishing them, trades, event cards, automatic recovery and manual local save/resume. It is localized in **Italian, English, French and German**.

- eight selectable CPU friends: the seven preserved KludgopolB personalities plus Pazifik, each with a localized friend card and a Grugnetto Go! character pawn;
- an illustrated four-island board (Prato di Casa, Bosco degli Scoiattoli, Dune Dorate, Miniera di Pietra) with 32 spaces, drawn from one background image plus a JSON layout;
- each ownable place shows one amount: its price in green while it is free, then the rent it collects once owned (brown, gold with embellishments, struck-through grey when pledged, ×N of the dice for special places), computed by the same `rentTerms` rule the engine charges;
- CPU turns are reviewed action by action in the right-hand column and end with an **OK** button; the same review is reachable from the bottom dock on phones;
- four-language **How to play** manual, board zoom, active-player follow mode and normal/fast animation speed;
- short **sound effects** for what happens between players (dice, purchases, rent, trades, cards, pledges, embellishments, Base Camp), on by default at a low volume, with an off/low/medium/high control in the toolbar (see `specs/sound.md`);
- arcade-style floating amounts (green **+100**, red **−120**) whenever money moves, over the player's cash and their pawn (see `specs/money-pops.md`);
- keyboard-accessible board spaces, live-region announcements and `prefers-reduced-motion` support;
- a **Reset local data** command that deletes only this game's keys from the browser origin;
- no visible deterministic seed and no internal AI-level labels in normal play.

The page is locked to the screen height; secondary dialogs scroll internally when needed.

## Run

The game has no runtime dependencies. Node.js is needed only for the local static server and the development tools.

```bash
npm run dev        # serve public/ on http://localhost:8080
npm run build      # copy public/ to game/ (gitignored deploy export)
npm start          # build, then serve game/
npm run check      # lint + tests
npm run release:check   # tests, QA flow and HTTP smoke check
```

Simulation and calibration tools:

```bash
npm run sim -- --seed 12345
npm run arena -- --games 100 --seed 1000
npm run landing -- --runs 500 --turns 4000
npm run calibrate -- --games 100 --seed 40000
```

### Board number editor

The position of each space number is a hand-tuned value stored in `layout.json` (`numberPositions`). To adjust them, open the game with `?numberEdit` (for example `http://localhost:8080/?numberEdit`): the numbers become draggable and **Export** downloads a JSON file in the same format as `numberPositions`. The editor is not available without that parameter.

## Board and content

The default and only packaged board is `boards/grugnetto-32-v1.4/`. Presentation geometry is separate, under `boards/layouts/grugnetto-islands/`: the background image, the position of every space, pawn anchors, bridge waypoints, number positions and the derived plaque outlines (`tile-outlines.json`, regenerated by `scripts/extract-tile-outlines.py`), which the UI uses for the per-player tint, the spotlight and precise clicks.

Earlier board revisions (v1.0–v1.3) are no longer packaged. During their life, RC33 made **metadata/footer-only wording redactions** in them (a trademark scrub); prices, rents, landing weights, groups and event mechanics were not changed. Mechanical changes require a new content version rather than silently rebalancing an existing board. CPU-only behaviour is reproducible: internal diagnostic seed `12345` produces **Hans in 106 turns**. The seed is a test and replay detail and is never shown in the game.

## Archaeology and licensing

The package keeps provenance, hashes and the upstream KludgopolB changelog, and intentionally redistributes **none of the audited upstream ZIP archives**. KludgopolB and JAtlantik source snapshots are external evidence identified by URL and SHA-256 in `reference/EXTERNAL_ARTIFACTS.md`.

Automated tests cover deterministic engine behaviour, mixed human/CPU games, save/resume, corrupted-save recovery, board integrity, localization, accessibility hooks, the viewport policy, rare gameplay branches and the public-clean archive policy.
