# Grugnetto Go! enemy pawn assets

RC45 reuses enemy sprites from the sibling `grugnetto-go` project in the same upstream
`linkingtechnologies/libre-arcade` repository. Grugnetto Go!'s `public/LICENSE.txt` identifies
Kenney terrain/platform/enemy/prop/background artwork as CC0 1.0. These files therefore remain
under their original CC0 terms.
