# Optional modern background music

Nova Pinball v0.2.3 historically shipped tracker music credited to **Beyond**. Those tracker modules are **not redistributed** by this web restoration because the surviving materials do not document sufficiently clear redistribution/sublicensing terms for the modified web port.

The 1.0.0 restoration includes an explicitly optional **modern music layer**. This is an intentional modernization/divergence, not archaeological restoration.

Available choices:

- **None** — most conservative/archival presentation;
- **Dreamy Orbit** — calm space/arcade loop, CC0;
- **Arcade Pulse** — more energetic arcade loop, CC0;
- **Wormhole Drive** — darker space loop created for this restoration, CC0;
- **Playlist** — rotates through all three tracks.

Music volume is stored separately from SFX volume. The selection is also persisted locally.

The first two arrangements are clean re-syntheses/adaptations of musical structures from the CC0 music generator in `manuel-palacio/brickstorm`; the third is original to this restoration. All runtime files contain only oscillator/noise synthesis and no samples from Nova Pinball or Beyond.

Exact credits, hashes and license information are in `public/assets/music-modern/CREDITS.md`.
