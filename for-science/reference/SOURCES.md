# Preserved sources

This directory contains untouched reference material for **For Science!** by Juan J. Martínez (reidrac).

## Archives

- `archives/forscience-final2.tar.gz` — PyWeek 16 final release 2, 20 April 2013. The uploaded file had a `.tar` name but its bytes are gzip-compressed; this copy only restores the upstream filename extension.
- `archives/forscience-1.0.1.tar.gz` — post-compo release 1.0.1, 22 April 2013.

SHA-256 values are in `archives/SHA256SUMS`.

## Extracted trees

- `pyweek-final2/` — extracted PyWeek final release, otherwise unmodified.
- `postcompo-1.0.1/` — extracted 1.0.1 release, otherwise unmodified.

The `*.SHA256SUMS` files record hashes for every extracted file.

## Upstream locations

- PyWeek 16 entry: https://pyweek.org/e/useboxnet3/
- Author page: https://www.usebox.net/jjm/for-science/

Do not edit files below `reference/`. Any browser-port changes belong outside this directory.
