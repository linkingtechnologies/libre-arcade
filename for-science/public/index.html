How to Play

Match 3 or more cells to collect money, attacks and shield repairs.

Each turn, either swap two adjacent cells or use one available item. Destroy Dr Z's base before he destroys yours.

Mouse / touch: select cells or items. ESC: return to the menu. Ctrl/Cmd + F: fullscreen.

Original game by Juan J. Martínez for PyWeek 16, 2013.
