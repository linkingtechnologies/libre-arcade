# Changelog

## Unreleased

- First public version, joined to the Libre Arcade collection: the third and last game from Jonathan Hulka's Virtual Toybox Puzzle Collection, after Libre Jigsaw and Sliding Tile Puzzle.
- Added the collection's scaffolding: `package.json` (scripts `dev`, `build`, `start`, `test`, `lint`, `check`, plus `bundle` to regenerate `public/app.bundle.js` from `src/`), `scripts/serve.mjs`, `scripts/build.mjs`, an ESLint config, `.gitignore`, the GoatCounter snippet and a "Play here" link. `COPYING` was two lines pointing at `LICENSES/GPL-3.0.html`; replaced with the full GPL-3.0 text the collection's rules require at the root.
- Made `npm test` independent of a JDK. The delivered `spinner-parity.cjs` compiled and ran a Java oracle program live on every test run; it was re-run here against the real `reference/puzzlegames.jar` (Java 1.8.0_503) across geometry, shuffle and single-spin modes, and its output stored as three fixtures, which the tests now check against. Added `test/reference-integrity.cjs`, `test/photo-integrity.cjs` and a Node port of the delivered `production-smoke.sh`'s static checks, combined with the existing tests into `test/run-all.cjs`: 7 checks in total, all JDK-free. `test/production-smoke.sh` was rewritten to re-verify the stored fixtures against a live JDK re-run instead of silently doing nothing with its own compile step, and remains available as an optional full check.
- Verified independently and recorded in `PROVENANCE.md` and `SOFTWARE_ARCHAEOLOGY.md`: the board geometry, shuffle algorithm and spin mechanics, all against the live original Java classes; the ten photographs, thumbnails and two rotation cursor icons byte-identical to the historical jar; and the GPL "or later" header read directly in `SpinnerHandler.java`.
- No change to the game rules, the geometry, the shuffle algorithm (its seven-into-six no-op included), the spin mechanics, the background-color formula, the strings or the bundled assets.
