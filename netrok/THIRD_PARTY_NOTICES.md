# Third-party notices

## Netrok 0.95

Original game: **Netrok 0.95** by Ioan-Tudor Parvulescu. Original credits identify game idea, design, programming and graphics to the author and describe the music/sound effects as public domain. The historical project URL recorded in the recovered documentation was `http://www.itpsoft.de/main.html.php?seite=netrok`.

The Netrok source code states **GNU GPL version 2 or (at your option) any later version**. This browser port is distributed under GPLv3-compatible terms; see `LICENSE`. The original source material is not duplicated in this web release.

## SFont

The original game used SFont by Karl Bartel. The source permits GPL version 2 or later (and notes GPL/LGPL choice in its header). This browser build includes a JavaScript adapter reproducing the original bitmap font layout behavior and the original Netrok bitmap font asset.

## Music compatibility renders

The untouched original Netrok MIDI files are included under `assets/midi/`. The OGG files under `assets/music/` are browser compatibility renders generated from those MIDI events using mathematical waveforms only. No external SoundFont, instrument sample library or ROM is embedded or redistributed. The compatibility render does not claim to reproduce a particular historical MIDI device.


## Enhanced graphics

- `assets/png-cleanhd4x/` and `assets/presentation-cleanhd4x/` are enhanced versions derived from the original Netrok graphics. No generative image model is used for these files.
