Instructions

Move

← → move · ↑ ↓ climb ladders.

Jump & run

Space / Alt jumps. Shift / Ctrl runs.

Checkpoint flag

Home / Delete places your one jump-in flag for the level. It costs score and cannot be redeployed in the same level.

Shields

Use numpad 8/4/2/6 to select the shield to move, then its destination. A transfer costs score. Collect 20 red shield coins for a new shield.

Enemies

Attack from a safe side. Spikes matter: upgrades can let Netrok survive attacks that are otherwise lethal. Avoid the large spikes.

Score & lives

Helpful actions can cost points; fast level completion and defeated enemies add points. Every 5,000 points earned grants an extra life.

About

Netrok is a platform game created in 2004 by Ioan-Tudor Parvulescu.

This edition adds modern controls, saving, display options, cheats and a level editor.

Credits and license details are included with the game files.
