# Original Netrok material

This directory preserves the historical material used to build the web port.

## `source/netrok-0.95/`

Recovered Netrok 0.95 C++/SDL source tree, including the original level editor source, build scripts, documentation and GPL license text. The source was recovered from the preserved OpenPandora package and is kept here as reference material rather than rewritten or reformatted.

## `packages/`

- `netrok-0.95-os4.lha` — preserved AmigaOS 4 package used as a source for the original game assets and level data.
- `netrok-0.95.1.01-pandora.pnd` — preserved OpenPandora package from which the Netrok 0.95 source tree was recovered.

The browser implementation lives outside `/reference`; this directory exists to keep the historical source and packages available for comparison and preservation.
