# Netrok 0.95 — Web Edition

**[▶ Play here](https://linkingtechnologies.github.io/libre-arcade/netrok/index.html)**

A browser edition of **Netrok 0.95**, the 2004 platform game by Ioan-Tudor Parvulescu.

## Play

Serve this directory with any small static web server and open `index.html`. No backend is required.

## Features

- all 20 original levels
- responsive desktop and mobile layout
- keyboard and touch controls
- automatic save and continue
- English and Italian interface
- music and sound controls
- Original, Soft and Enhanced display modes
- optional Cheat Mode
- built-in Level Editor with import, export and playtest
- custom levels kept separate from the normal high score

The **Classic menu** preserves the original in-game presentation and remains in English.

## Controls

Full controls and gameplay instructions are available from **Menu → Instructions**.
