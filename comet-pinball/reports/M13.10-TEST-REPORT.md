# Upper bumper investigation — evidence and tests

## Native traces and isolated comparisons

`tools/oracle/M1310BumperUpperOracle.java` produced **1,170** one-frame initial states near the region above the bumpers, using the historical JAR. A conservative geometric filter retained **990** states initially within the approximate arc; this is not a complete game replay and some initial contacts needed further validation.

Of these 990 states, **441** had a native upper-curve fixture contact. The earlier implementation missed swept contact in **322** cases with position error above 5 mm. After the focused patch, **22/990** still exceeded 5 mm, **10/990** exceeded 1 cm and **8** native curve contacts remained unmatched. Complete isolated-state parity was **not** achieved.

`M1310BumperSequenceOracle.java` generated nine 45-frame sequences starting near all three bumpers, applying the original post-contact force. The previous JavaScript solver exceeded the approximate upper boundary in 2/9; the revised solver did so in 0/9, with 9 curve sweeps and 8 sequences containing a bumper hit. None of these nine native sequences exited the approximate boundary. Some JS/native trajectories still differed substantially; the limited containment test is not whole-game equivalence.

`tests/m13.10-upper-bumper.js` includes five isolated impact comparisons (left/right curves and ceiling precedence), plus nine 45-frame sequences (405 frames). The older divider, central-ceiling and full-game differential regressions remained active.

## Remaining questions at the time

The launch lane needed a coupled-contact investigation. Mixed curve/ceiling impacts retained the 22/990 position discrepancies and eight missing curve contacts. The full replay first exceeded 1 mm around frame 407, with material velocity divergence around frame 434. The managed browser used inline production assets rather than hosted navigation.

This document describes an earlier playable test build; do not treat it as a current 1.0 certification.
