# Geometry A/B oracle — Virtual Toybox 2010 vs Libre Jigsaw 2012

M3 preserves the historical geometry split instead of normalising both generations to one cutter.

## Square jigsaw: real historical change

The original `puzzlegames.jar` (2010.08.11) implements square edges directly in `SquareJigsawManager.buildEdge()`.
It uses:

- `bubbleMinFactor = 0.30`
- `bubbleMaxFactor = 0.40`
- `bubbleStemFactor = 0.30`
- `controlPointVarianceFactor = 0.10`
- `cornerVarianceFactor = 0.20`

Libre Jigsaw later moves shape generation into `JigsawCutter` and changes the square tuning to:

- `bubbleMinFactor = 0.30`
- `bubbleMaxFactor = 0.40`
- `controlPointVarianceFactor = 0.05`
- `cornerVarianceFactor = 0.12`

The edge construction itself also changes. Therefore M3 provides two selectable square cuts rather than treating the 2012 cutter as a refactor-only replacement.

## Hex jigsaw: no fabricated delta

The 2010 `HexJigsawManager` already uses the edge construction later generalized into `JigsawCutter`. Its tuning remains `0.20 / 0.25 / 0.05 / 0.10`, with the same expanded-grid ownership and clipping model. M3 therefore delegates the 2010 hex style to the preserved common implementation and marks it as historically equivalent to the 2012 geometry.

## Java layout oracle

`geometry2010-smoke.mjs` contains layout values generated directly by constructing the original 2010 Java `SquareJigsawManager` from `puzzlegames.jar`. It verifies grid dimensions, tile count, tile size and board offsets across landscape, portrait and small/large boards.

The seeded JavaScript random generator is a restoration test aid; it is not claimed to reproduce `java.util.Random` byte-for-byte. The preserved invariant is the original geometry/range/ownership algorithm.
