# AGENTS.md

- License: GPL-3.0-or-later, from the headers of both preserved generations (`puzzlegames.jar` and `libre-jig-master.zip`). The ten bundled photographs are separately licensed CC BY-SA 3.0 US (JS Nature Photos); keep that attribution in `THIRD_PARTY_NOTICES.md`, `LICENSES/` and the in-game Credits dialog, and never fold it into the GPL notice.
- `reference/` holds the actual historical archives, not just their hashes: `puzzlegames.jar` (2010), `puzzles20100726.zip` (2010, an earlier snapshot), `libre-jig-master.zip` (2011-2012). This is unusual for this collection; keep it that way rather than reducing it to a manifest, and never edit, repack or recompress them. `test/reference-integrity.mjs` checks all three against `reference/SHA256SUMS.txt` as part of `npm test`.
- Two square-cutter generations are both real and both kept: `src/geometry2010.js` (`SquareJigsawManager.buildEdge()`, distinct tuning) and the square half of `src/geometry2012.js` (the later `JigsawCutter`-based cutter). Do not treat one as a superseded version of the other or collapse them into a single implementation; `specs/GEOMETRY_2010_2012.md` (in `test/`) and `specs/port-map.md` explain why they differ. The hex cutter is historically equivalent between generations and is not duplicated.
- Two snap policies are both real and both kept: `planSnap2010` (weighted-average recentering) and `planSnap2012` (largest-on-board-group anchor, introduced 2011-02-08 per the preserved `libre-jig-master.zip` changelog). Do not remove either; `test/snapping-smoke.mjs` covers both.
- `test/Print2010Layout.java` is an executable oracle, not documentation: it compiles and runs against the real classes in `reference/puzzlegames.jar` (`javac --release 8`, Java 8 runtime) and its output must keep matching `test/oracle-layout-2010.csv`. If the JavaScript geometry ever changes, re-run this oracle before touching the recorded CSV.
- `public/app.bundle.js` is generated from `src/*.js` by `scripts/build-bundle.py` (`npm run bundle`), because the page loads it as a classic script so the game also works from `file://`. It is committed, not gitignored: `public/` must stay immediately playable with zero build step, so the bundle is checked in like any other file under `public/`, and regenerating it is a manual step, not part of `npm run build` (which only packages `public/` into `game/`, unchanged, per the collection contract). Never hand-edit the bundle; edit `src/` and run `npm run bundle`.
- The Java `.ljf` format is deliberately not read or written. A legacy file (`version:` prefix) must be detected and reported clearly, never guessed at or silently misparsed. The browser format is `libre-jigsaw-html5`, currently version 2; a version-1 (Beta 2) save must remain loadable.
- The player-facing UI must never expose the historical-parity controls (a cut-generation selector, a snap-policy selector) or the internal vocabulary that names them (`ConnectedSet`, "milestone", "Piece style", "Snap policy"); `test/production-smoke.mjs` asserts their absence from `public/index.html`. Historical parity stays selectable in the test/oracle layer, not in the shipped menu.
- No frameworks, no external libraries. `npm run check` (ESLint plus the 13-file test suite in `test/run-all.mjs`) must pass before packaging.
- `SHA256SUMS.txt` at the game root covers every shipped file (distinct from `reference/SHA256SUMS.txt`, which covers only the three historical archives); regenerate it when any packaged file changes.
