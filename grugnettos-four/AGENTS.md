# AGENTS.md

- Licence: **GPL-3.0-only for the game as a whole, with the Pascal Pons module under AGPL-3.0-or-later.** Evidence is in `PROVENANCE.md`; read it before touching any licence label. Never write "or later" for an upstream unless its own headers say so: Stratzilla ships only the GPLv3 text (so it is GPL-3.0-only, and that makes the whole distribution GPL-3.0-only), and the GNOME Gnect/Velena headers name the GNU GPL with no version at all (the adapters are GPL-3.0-only by recipient's choice under GPLv2 section 9). `reference/gnome-gnect-velena/SOURCE.md` still says "GPL version 2 or later"; that sentence is the delivery's own record, is not supported by the retained headers and is deliberately left as delivered inside the frozen `reference/` tree.
- The Credits dialog links to the source and licences (`sourceLink` in `public/src/ui/app.js` and `public/index.html`). That link is how the AGPL-3.0-or-later Pons module offers its source to people who play over the network (AGPLv3 section 13). Do not remove it, and keep it pointing at this game's folder.
- `reference/` is frozen: never edit, reformat or "tidy" it. Every preserved upstream folder has a `CHECKSUMS.txt` (the UCI dataset lists its three checksums in `SOURCE.md` instead); verify them after any change near them. The files use two conventions: the Aman Virmani and GCompris lists hold paths relative to the game root (`sha256sum -c reference/<folder>/CHECKSUMS.txt` from there), the others are relative to their own folder. In the Downing, Bell and Zeta36 lists the last line points at the generated weights module as `../../src/players/...`, the layout before `public/` existed; the module now lives under `public/src/players/`, so run those with `sed 's#\.\./\.\./src/#../../public/src/#'` (all verified identical). Do not edit the lists. The Childsplay `fourrow.py`, the Al Sweigart source and the Allis thesis are **not** preserved there (a `SOURCE.md` record only); do not describe them as preserved.
- Never change a player's search, evaluation, move ordering or tie-breaking to adjust difficulty. The six levels come from the measured Arena ranking frozen in `public/src/strength/strength-snapshot.js`; `tools/calibrate-strength.mjs` replays it. If any adapter changes, re-run the calibration and regenerate the snapshot; never edit the ratings by hand.
- The large `public/src/players/*-weights.js` and `*-knowledge.js` modules are generated data. Regenerate them with the tools in `tools/` (see the table in `specs/port-map.md`), never by hand. All six were checked to regenerate byte-identically (the Zeta36 converter needs `h5py`). They are excluded from ESLint on purpose. Adding another model means adding a lazy-loading step first: the first load already fetches about 12 MB of JavaScript.
- `test/oracle-fixtures.mjs` decides whether a native or Python oracle runs live (`CONNECTLAB_LIVE_ORACLES=1`, `npm run test:live`) or replays `test/fixtures/*.json`. Never edit a fixture by hand and never copy one to make a test pass: re-record it with `CONNECTLAB_LIVE_ORACLES=1 CONNECTLAB_RECORD_ORACLES=1`. Nine oracles are recorded: the four C transcriptions, GCompris and Downing (recorded on Windows), and the three that compile the preserved C++ (Stratzilla, PetterS, Pons), recorded under Debian 12 in WSL with `g++` 12.2 and Node 18. Run an oracle live without `CONNECTLAB_RECORD_ORACLES=1` first: recording happens before the test's own assertions, so a recording does not by itself prove the port agrees. A test whose recording is missing is reported as SKIPPED by `npm test`, never as passed.
- The four small C oracles (`test/gnome-velena-*-native-oracle.c`, `test/kfourinline-native-oracle.c`) are independent transcriptions, not builds of the preserved sources. They support "Level 2" claims only; do not describe the Velena or KFourInLine ports as verified against the original code.
- Run the tests from the game root (`npm test`): they use root-relative paths such as `reference/...` and `tools/...`. Browser files live in `public/` (`public/src`, `public/arena`, `public/index.html`); tests, tools, `reference/`, `docs/` and `specs/` stay at the root. Paths inside `docs/development/PORTING_NOTES*.md` still say `src/...`: read them as `public/src/...`.
- The Python generators must keep writing LF (`newline="\n"`), otherwise a Windows run produces CRLF and the regenerated modules differ from the committed ones.
- Sound: `tone()` in `public/src/ui/app.js` must keep using one shared `AudioContext`; creating one per beep exhausts the browser's context limit.
- `public-ui.mjs` requires `CHANGELOG.md` to have exactly one `## ` heading (`## 1.0.0`) and no milestone-style labels. Internal milestone labels remain only in `docs/development/` and in the `version` field of the strength snapshot, neither of which players see.
- "CONNECT 4" is a trademark of Hasbro (registration status not checked). The independence notice naming it lives in the README only; the game itself (Credits dialog, strings, page) carries no mention of Hasbro, by decision, and `test/public-ui.mjs` enforces both halves. Beyond that notice the name appears only in the historical names of upstream projects (`pascal-pons-connect4`, `gcompris-connect4-4stattack`, ...), never in this game's own name, folder or branding. Keep it that way.
- No framework, bundler or build step: `public/` runs as native ES modules and `npm run build` only copies it to `game/`.
