# Changelog

## 1.0.0

- First public release of Grugnetto's Four.
- Added bilingual human-versus-computer play with six difficulty levels.
- Included 23 preserved, derived and control intelligences behind a common player interface.
- Added the optional Laboratory and Arena inside the Advanced area.
- Added responsive viewport fitting, chip animations, winning-line highlights and result overlay.
- Added source provenance, license notices, historical parity tests and deterministic Arena checks.
- Joined the Libre Arcade collection: the browser payload (`index.html`, `src/`, `arena/`) moved into `public/`, with the tests, tools, `reference/`, `docs/` and `specs/` staying at the game root. Added the collection scaffolding: `package.json` scripts (`dev`, `build`, `start`, `test`, `test:live`, `lint`, `check`), `scripts/serve.mjs`, `scripts/build.mjs`, an ESLint config, `.gitignore`, the GoatCounter snippet and a "Play here" link.
- Made the parity suite runnable without a compiler. The oracles that compile C or C++, or run Python, hard-coded `cc`, `g++`, `python3` and `/tmp` paths, so none of them could run on Windows. They now go through `test/oracle-fixtures.mjs`: live when `CONNECTLAB_LIVE_ORACLES=1` (`npm run test:live`), otherwise a replay of the output recorded in `test/fixtures/`, each recording tied to the SHA-256 of its inputs. Nine oracles were run for real and recorded: four C transcriptions with MinGW GCC 6.3, the GCompris Python oracle and the Downing neural-network oracle on Windows, and the three that compile the preserved C++ (Stratzilla, PetterS, Pons) with g++ 12.2 on Debian 12 under WSL, where all three agree with the original code. A test whose recording is missing is reported as SKIPPED, never as passed.
- Re-derived all six trained-data modules with the tools in `tools/`: Markus Thill weights, the UCI count table, Michael Bell's 10,000-game table, Aman Virmani's Q-table, Jacob Downing's 100-generation weights and the Zeta36 weights (with `h5py` in a scratch virtual environment) all regenerate byte-identically from the preserved sources. The NumPy oracle for the Zeta36 network, re-run on the original HDF5 file, also reproduces `test/zeta36-oracle.json` byte for byte. The Python generators now write LF explicitly, because text-mode output on Windows produced CRLF and differed from the committed files in line endings only.
- Corrected an unsupported licence claim. The five GNOME Gnect/Velena adapters were labelled `GPL-2.0-or-later`, but the retained Velena headers only say "released under the GNU General Public License with Giuliano's approval": no version, no "or later". They are now labelled `GPL-3.0-only`, with the basis stated in each file (a GPL grant without a version number lets the recipient choose any version, GPLv2 section 9). `THIRD_PARTY_NOTICES.md` now also records that the Stratzilla repository grants GPL version 3 with no "or later" clause (so the combined game is GPL-3.0-only plus the AGPL-3.0-or-later Pons module), that the Childsplay module is not preserved under `reference/`, and uses descriptive names instead of internal milestone labels.
- Fixed the interface sound: every beep created a new `AudioContext` and none was ever closed, which exhausts the context limit in some browsers (Safari allows very few); a single shared context is now reused and resumed when suspended. The peak volume is now 0.09 (it was 0.05) with a slightly longer decay, because the tones were technically playing but too quiet to notice.
- Added a "Source code, authors and licenses" link to the Credits dialog (English and Italian), so that the source of the AGPL-3.0-or-later Pons module is offered to everyone who plays, as AGPLv3 section 13 requires of a modified, network-served program.
- Added `tools/calibrate-strength.mjs`, which replays the Arena calibration behind the six difficulty levels and compares it with the frozen snapshot. Run for this release, it reproduced all 23 snapshot rows exactly (1,518 games, about 11 minutes).
- Fixed the status text overlapping the board on short windows: the line above the board ("Your turn" and its subline) was covered by the grid by about 10 px at 1070 by 632, because the board was sized from a fixed guess of the header and padding heights. The board is now sized from the space its container actually has, the two status lines are kept to a single line each, the "LIBRE ARCADE" line was removed from the header (the Credits and the footer still name Libre Arcade), and the "'s" after the pig in the menu title is now set like the one in the header, so it reads as lowercase. Checked at 81 window sizes between 320 by 420 and 1600 by 860, three times over, with no overlap, and the screenshots were retaken.
- No change to any player's move selection, search, evaluation or tie-breaking, to the six difficulty clusters, or to any preserved source under `reference/`.
