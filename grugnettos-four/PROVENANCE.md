# Provenance

Grugnetto's Four is a **ported** collection: 21 of its 23 players are JavaScript re-implementations of decision logic taken from 16 historical sources (programs, a thesis, a dataset), and the remaining 2 are original ConnectLab players: an ensemble of five of the ports, and a control baseline. The browser game, the common player contract, the Arena and the strength calibration are new code. Nothing here is a clean-room set of opponents.

This file gives, for each source, the most precise revision that exists, the licence and the kind of evidence behind it, and how it was treated. The per-source wording lives in [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md); the function-level mapping and the verification level of each port are in [`specs/port-map.md`](specs/port-map.md); untouched snapshots and source records are under [`reference/`](reference/).

## Licence of the whole: GPL-3.0-only, with one AGPL module

- **Not "GPL-3.0-or-later".** Stratzilla's repository carries the GPLv3 text and nothing else, so its port can be offered under version 3 only, and that sets the ceiling for the combined work. Childsplay's header applies "version 3"; whether it adds "or later" was not checked and is not claimed.
- **The Pascal Pons module stays AGPL-3.0-or-later.** AGPLv3 section 13 and GPLv3 section 13 allow the two to be combined in one distribution; the AGPL file keeps its own terms. AGPLv3 section 13 also obliges a modified version that people use over a network to offer them its source. The game is served over a network, so the Credits dialog links to this folder (`sourceLink` in `public/index.html`), which holds the source and every licence.
- **Velena is GPL by recipient's choice.** The retained headers read "It is released under the GNU General Public License with Giuliano's approval", with no version number and no "or later". GPLv2 section 9 says that a program which specifies no version may be used under any version ever published, so the five adapters are distributed under GPL-3.0-only on that basis. The delivery's own record, `reference/gnome-gnect-velena/SOURCE.md`, says "GNU GPL version 2 or later"; the headers do not support that sentence. It is left unedited because `reference/` is frozen, and this file is where the correction lives. The earlier adapter headers repeated the claim and were corrected to GPL-3.0-only.
- **KFourInLine** is LGPL-2.0-or-later in the AI files, which allows choosing a later LGPL or the GPL, so it is compatible with GPLv3.
- **MIT, BSD-3-Clause** sources keep their notices in `reference/` and `THIRD_PARTY_NOTICES.md`.
- **Derived data is not relicensed.** `uci-naive-bayes-knowledge.js` is a derivative of a CC BY 4.0 dataset and carries that attribution. The Zeta36 weights are a lossless repacking of an MIT-licensed model, and the Markus Thill weights of an MIT-licensed export.

## Derived data and what it is

Six large modules in `public/src/players/` are data, not code. Each is regenerated by a tool in `tools/` (table in [`specs/port-map.md`](specs/port-map.md)). Four of them are **not upstream models**: no upstream trained population or table exists for Bell, Downing and Virmani, and the UCI counts are an adaptation of raw rows. They are labelled as ConnectLab snapshots wherever they appear, never as the original author's model.

## What was independently checked in this integration

- **Licence headers:** read in the retained sources for the Pons, Bell, GCompris, KFourInLine and Velena files, and the licence files for Melilli, PetterS, Stratzilla, Thill, Downing, Zeta36 and Virmani. Two corrections came out of it: the Velena version claim above (the five adapters' headers said GPL-2.0-or-later), and the Stratzilla notice, which said only "GNU GPL version 3" and now states that no "or later" grant exists.
- **Preserved checksums:** every `reference/*/CHECKSUMS.txt` verifies against the files on disk (see the note on path conventions in [`AGENTS.md`](AGENTS.md)).
- **Strength calibration:** `node tools/calibrate-strength.mjs` replayed the whole Arena calibration (1,518 games, 3 seeds, 23 players) in 664 seconds and reproduced all 23 snapshot rows exactly: rating, confidence interval and win/draw/loss counts. The six difficulty levels therefore follow from the frozen ranking and from nothing else.
- **Regenerated data:** all six data modules were regenerated from their preserved sources and compared byte for byte (the Zeta36 weights with `h5py` in a scratch virtual environment). The Zeta36 NumPy oracle, re-run on the original HDF5 file, also reproduces its recorded vectors byte for byte.
- **Parity tests:** All 29 test files pass. The three whose oracle compiles preserved C++ (Stratzilla, PetterS, Pons) were run live against the original code on Debian 12 with g++ 12.2 and then recorded, so the suite replays them on machines without a compiler. [`specs/port-map.md`](specs/port-map.md) states, player by player, whether the oracle is the original code (Level 1), an independent transcription (Level 2) or a source-level review (Level 3). Only the Melilli, Downing, Stratzilla, PetterS and Pons checks are Level 1 (PetterS for state, winner and move generation only).
