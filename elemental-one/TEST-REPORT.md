## Console, network and assets

- **Console errors:** one per page load, `DataCloneError: Cannot decode detached ArrayBuffer`, thrown by Phaser 1.1.3 (the unmodified original produces it too). Tests allow exactly this message and nothing else.
- **Missing asset requests:** none for the restored game. (The original page served from `reference/` requests the withheld font files and `jump.wav` and gets 404s; that is expected, since they are deliberately not redistributed. It does not affect the oracle.)
- **External requests:** only `gc.zgo.at` (GoatCounter), the collection-wide snippet required by the repository's `AGENTS.md`. The game itself needs no network once loaded.

## Notes and caveats

- Running the browser tests while another heavy job (such as the parity run) is using the CPU makes some of them time out. They passed 10/10 when run alone, and failed in a combined parallel run for that reason only; hence the serial `test` script.
- The parity test takes about 12 minutes (about 20 browser launches). `E1_FAST=1` runs only the four level scenarios; `E1_SKIP_BROWSER=1` skips all browser tests.
- Screenshots are regenerated by every run of the browser tests.
