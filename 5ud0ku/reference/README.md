# reference/

The historical material behind this game is kept light and reproducible, not as a copy of the whole archive.

- `5ud0ku-1.8/SOURCE.md` says where the archive comes from (the authors' manual page and the Internet Archive's snapshot of the source zip), gives the size and SHA-256 of the source zip, the jar and the descriptor, and says what is kept and what is not.
- `5ud0ku-1.8/ARCHIVE_SHA256.txt` lists all 55 files of the source archive with their SHA-256.
- `5ud0ku-1.8/source/` and `release/` keep what is needed to document and run the game, unmodified: the Java sources, the dictionaries, the build notes, the licence files and the descriptors.
- The zip, the jar and the nine PNG images (the icon and the digit sheets) are not redistributed: nothing says who drew the images. The same rule is used for Bomber and XO World.
