# Changelog

## 1.0.0 — Libre Arcade restoration

Initial production release of the browser restoration.

- faithful JavaScript port of the 5ud0ku 1.8 generator and solvers;
- deterministic QA oracles and 300-puzzle uniqueness regression;
- Web Worker isolation for generation and expensive custom solving;
- historical gameplay semantics for pencil marks, hint, conflict checking and undo/redo;
- binary-compatible save/load format with autosave and named saves;
- Custom Puzzle with Solve and Solve & Play;
- responsive EN/IT browser UI with mouse, touch and keyboard input;
- accessibility and local-data reset hardening;
- original source/JAR/JAD preserved under `reference/`.
