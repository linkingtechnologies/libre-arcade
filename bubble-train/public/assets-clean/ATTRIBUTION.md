# Clean asset provenance

All files in `assets-clean/svg/` were created specifically for the Bubble Train Restoration project as clean-room replacements.

They were not traced from, extracted from, or generated by sampling the original Bubble Train PNG/WAV/font assets.

Intended license: **CC0-1.0**.

Historical Bubble Train artwork remains excluded from the runnable restoration.

Theme background SVGs under `assets-clean/themes/` were likewise created as
new clean-room environment art inspired only by the broad names of the original
themes (default, arctic, beach, mexico, mountains, sea, sky, space).
