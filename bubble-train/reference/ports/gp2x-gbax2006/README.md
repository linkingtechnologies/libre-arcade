# GP2X / GBAX 2006 derivative

Contest entry preserved exactly as received. It is a derivative port and **not** the parity baseline. The archive contains no C/C++ source files, but does contain GPLv2 text, binary, resized/reworked graphics, OGG music, and 61 adapted levels.

All 61 level paths have counterparts in the OS4 package, but **0/61 are semantically XML-identical** after normalizing away whitespace. The adapted levels change coordinates and/or gameplay parameters such as speed for the 320x240 target; this is not merely archive metadata.

GBAX 2006 page: https://gbax.gp2x.de/gbax2006.html
