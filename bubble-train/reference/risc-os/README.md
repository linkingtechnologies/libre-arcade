# RISC OS port

Alan Buckley's historical RISC OS page lists both a 3.46 MB game archive and a 201 KB source archive (`bubtrainsrcr2.zip`). It documents 24 Jan 2006 changes including screen-mode command-line options and a 16bpp default for speed.

Page: https://sites.google.com/site/alansriscosstuff/bubble-train

The public Google Drive source file was identified but is not bundled here. Recover it separately and hash before extraction.
