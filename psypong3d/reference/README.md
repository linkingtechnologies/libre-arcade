# Reference material

`original-source/psypong3d-0.9/` preserves the text and C source files from the audited 0.9 upstream release without modification.

The historical BMP textures are intentionally omitted because the 0.9 README attributes two of them to external web sources but does not establish a GPL-compatible media license. See `audit/LEGAL_AUDIT.md`.

The complete historical tarball is therefore not redistributed in this repository.
