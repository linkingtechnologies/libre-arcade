# Release checklist

- [x] GPL-3.0-or-later code license verified from the original archive.
- [x] Ambiguously licensed historical textures excluded.
- [x] Replacement artwork included with provenance and project license documented.
- [x] Gameplay core independent from WebGL.
- [x] Automated deterministic core tests pass.
- [x] WebGL failure has a user-facing fallback.
- [x] Keyboard and touch controls implemented.
- [x] Single-player mobile controls hide the CPU side.
- [x] IT/EN UI and instructions included.
- [x] Options and language persist locally.
- [x] No framework, CDN or backend dependency.
- [x] No vertical document scrolling; panels constrain themselves on short displays.
- [x] Static-hosting paths are relative.
- [x] Favicon and description metadata included.
- [ ] Optional archival parity exercise: compare perceived pacing/camera motion with a native 0.9 executable on a documented reference setup.
