# Assets

The historical PSY PONG 3D 0.9 BMP media are **not** redistributed in this repository because the upstream archive does not establish sufficiently clear GPL-compatible rights for the externally sourced images.

This web restoration instead contains three newly created replacement assets:

- `game-background.png` — fullscreen psychedelic background used during play and demo mode.
- `floor-vortex.png` — texture mapped onto the 3D playing surface.
- `menu-background.png` — fullscreen menu backdrop with a darker area for readable UI.

These replacement artworks were created specifically for this restoration in September 2026 using an image-generation model, taking only the broad late-2000s psychedelic/cosmic mood of the historical game as visual direction. They do not contain the historical bitmap files.

The replacement assets are distributed as part of this project under **GPL-3.0-or-later**.
