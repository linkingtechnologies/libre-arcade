# Replacement artwork provenance

PSY PONG 3D 0.9 shipped three bitmap textures (`menu.bmp`, `background.bmp`, and `spiral.bmp`). The legal audit in `reference/audit/LEGAL_AUDIT.md` explains why those historical media are not redistributed here.

To preserve the visual character of the game without importing the uncertain historical media, the browser restoration uses three original replacement images created for this project in September 2026:

| File | Purpose | Historical file replaced |
| --- | --- | --- |
| `game-background.png` | Full-window psychedelic/cosmic background | `background.bmp` |
| `floor-vortex.png` | 3D playing-field texture | `spiral.bmp` |
| `menu-background.png` | Menu backdrop | `menu.bmp` |

The replacements were generated from new prompts. The historical screenshot was used only as broad visual mood guidance (electric blue/cyan/magenta psychedelic space aesthetic); the old bitmap files were not used as source pixels for the replacements.

License for these replacement assets: **GPL-3.0-or-later**, as part of this restoration repository.
