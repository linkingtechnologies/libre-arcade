# Third-Party Notices

The executable port under `/src` contains no third-party visual or audio assets from the historical game.

Runtime graphics are newly authored procedural Canvas drawings. Runtime audio is synthesized with the Web Audio API.

Historical source material and original assets are kept separately under `/reference` for software-archaeology and verification purposes. The original project README states that, unless otherwise indicated in its credits, artwork is licensed under Creative Commons Attribution-NonCommercial 3.0. Those assets are **not used by the executable Libre Arcade port**.
