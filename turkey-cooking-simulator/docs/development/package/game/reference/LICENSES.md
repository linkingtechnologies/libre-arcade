# License separation

## New Libre Arcade port (`/src`, `/tests`, `/docs`)
GPL-3.0-only for code written for the preservation port.

## Historical source code
The upstream repository contains a GPLv3 `LICENSE` file. M1 anchors the exact source baseline by commit and Git blob IDs in `SOURCE.md`.

## Historical artwork and text/audio
The upstream README states that, unless otherwise indicated on the credits page, artwork is Creative Commons Attribution-NonCommercial (CC BY-NC 3.0) by Benjamin Kwok. These assets are therefore **reference-only** for this Libre Arcade effort and are not copied into `/src`.

Original dialogue/story text is also treated conservatively as reference-only pending item-level rights documentation. New dialogue for the final port must be newly written.

Audio must be re-audited item by item before reuse. M1 contains no original audio.
