# Original Memonix: Mosaic tiles

These 50 PNG files are lossless browser conversions of the original 64×64 Mosaic BMP assets recovered from `gamedata.vfs` inside `reference/memonix_1.6_src.tar.bz2`.

Original authorship: Michael Kurinnoy / Viewizard Games, Memonix 1.6 (2003–2006).

Licensing/provenance evidence is documented in:

- `../../reference/MemonixSourceCode-License.txt`
- `../../docs/ORIGINAL_ASSET_AUDIT.md`
- `../../THIRD_PARTY_NOTICES.md`

`original-asset-manifest.json` contains the per-file original BMP hash and distributed PNG hash.
