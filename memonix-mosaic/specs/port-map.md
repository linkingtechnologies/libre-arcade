## Verification level

Per this collection's verification hierarchy (see the root [`AGENTS.md`](../AGENTS.md)):

- **Level 1 (executable oracle)** for every redistributed asset: the VFS container, its RLE compression, and the BMP/PNG pixel data were all independently re-implemented from the original C++ source and public format specifications, then cross-checked byte-for-byte and pixel-for-pixel against the delivered package. See `PROVENANCE.md` for the exact figures (265/265 files, 50/50 tiles, 0 mismatches).
- **Level 3 (documented source-level review)** for gameplay behavior and menu geometry: the family/suffix/shape ordering and the four title-screen window coordinates were transcribed directly from reading the preserved source, but the specific difficulty/symmetry/mask generation function was not isolated and diffed function-by-function the way, for example, Netris's engine was. No C++ toolchain was available in this environment to build and run the original executable as an oracle for board generation.

This map does not claim oracle-level confidence for board generation, only for the recovered assets and the menu/asset-identifier layer above.
