# Changelog

## Unreleased

- First public version, joined to the Libre Arcade collection: a standalone HTML5 restoration of Mosaic, one of the four suite modes in Michael Kurinnoy / Viewizard Games' Memonix 1.6 (2006).
- Restructured the delivered package to this collection's `public/`/`game/` contract: `index.html`, `css/`, `src/`, `assets/` and `tools/` moved into a new `public/` folder, with `reference/`, `docs/`, `tests/`, `LICENSE` and the other project files staying at the game root. Added the collection's scaffolding: `package.json` scripts (`dev`, `build`, `start`, `test`, `lint`, `check`), `scripts/serve.mjs`, `scripts/build.mjs`, an ESLint config, `.gitignore`, the GoatCounter snippet and a "Play here" link.
- Determined the license is **GPL-3.0-only**, not this collection's usual GPL-3.0-or-later default: the recovered `MemonixSourceCode/License.txt` and every per-file C++ header name GPL version 3 with no "or later" clause. `LICENSE`, `package.json` and `PROVENANCE.md` all reflect this; see `PROVENANCE.md` for the full reasoning, a first for this collection.
- Independently re-verified every redistributed asset from first principles rather than trusting the delivered package's own extraction: wrote a from-scratch parser for Memonix's proprietary `.vfs` archive format and its RLE compression directly from the preserved `VFS.cpp`/`RLE.cpp` source, then a from-scratch BMP and PNG decoder, and used them to confirm all 265 files in `gamedata.vfs` decompress to their declared length with zero mismatches, and all 50 recovered Mosaic tiles plus the three menu/title assets are pixel-identical to the distributed PNGs (including the documented black-colour-key-to-alpha conversion). Recorded in `PROVENANCE.md` and `SOFTWARE_ARCHAEOLOGY.md`.
- Fixed two Options-screen layout bugs found during manual verification, both in this restoration's own new UI code (not recovered original behavior): the fifth difficulty button (D4) extended past the right edge of its panel, and the "Preview countdown"/"Tempo di memorizzazione" label overlapped the On/Off buttons because the available space (measured with `ctx.measureText`) was too narrow for the longer translations. Also raised the procedural click/error tone volume (0.035/0.045 → 0.09/0.12 peak gain, slightly longer decay), which was technically audible but too quiet to notice on typical speakers.
- No change to gameplay rules, board geometry, difficulty behavior, tile family/suffix order, historical masks, the four historical title-screen window coordinates, or any redistributed asset.
