# M0.9 RC5 — Front-end and UI acceptance pass

Adds a clean-room front-end without changing gameplay or calibrated physics.

- title/splash menu;
- Play and How to play;
- audio and language controls on the menu;
- return to menu from game over;
- HUD compact breakpoint for narrow screens;
- removal of archaeology/debug copy from player-facing artwork;
- physics paused while the menu is open.

The historical Flash menu was used only as evidence that a front-end existed; no visual assets or layout were copied.
