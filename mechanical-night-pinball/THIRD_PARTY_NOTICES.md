# Third-party notices

## Public runtime

The production build contains **no third-party runtime library or historical game asset**. It is vanilla HTML/CSS/JavaScript plus newly authored clean-room SVG artwork, procedural SFX, and an original bundled CC0 music loop. The music loop is project-authored and is not third-party content.

## Behavioural and archaeological references

- **DocDonkeys/Pinup-Pinball (2018)** — MIT-licensed source code; principal table/rules parity target. Historical expressive artwork/audio from its release is not redistributed here.
- **Box2D 2.3.2** — Erin Catto, zlib-style license; used as a numerical calibration reference through local C++ harnesses, not shipped as a runtime dependency.
- **SDL 2.0.4, SDL_image 2.0.0, SDL_mixer 2.0.0** — zlib-style licenses in the historical project; not used by the web runtime.
- **Historical Flash Pinup Pinball** — rights/license not established as free/open; behavioural/provenance reference only and not redistributed here.
