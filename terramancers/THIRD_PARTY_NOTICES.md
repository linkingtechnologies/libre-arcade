## Assets requiring additional provenance notes

### Baldric.png

The file is not named in Terramancers' `AUTHORS.TXT`, but its size/name/art match Stephen Challener's LPC entry **“Four characters: My LPC entries”**, which explicitly includes Baldric. The current OpenGameArt page displays CC-BY 3.0, CC-BY-SA 3.0, and OGA-BY 3.0; importantly, the 2012 LPC rules required art entries to be available under CC-BY-SA 3.0 and GPL 3.0 at entry time. We therefore preserve the broadest attribution record rather than collapsing the history into a single modern page label.

- https://opengameart.org/content/four-characters-my-lpc-entries

### sand.png

`sand.png` is used by the active `sand.cfg` but is omitted from the historical file-by-file `AUTHORS.TXT`. Daniel Eddeland's 2012 LPC farming submission explicitly states that it includes sand tilesets and is listed as CC-BY-SA 3.0 / GPL 3.0. The filename/date/context strongly support that source, but the omission in Terramancers' own attribution file is preserved as an audit caveat.

- https://opengameart.org/content/lpc-farming-tilesets-magic-animations-and-ui-elements

### greenTrees.png

`greenTrees.png` is not listed separately in `AUTHORS.TXT`. Visual inspection shows it is an assembled tree image built from the Lanea Zimmerman tree-top/trunk material that *is* named in `AUTHORS.TXT`. The exact historical assembly operation is not documented. The file remains preserved unchanged, and this inferred derivation is recorded rather than represented as certain authorship metadata.

## Generated tile atlases

`public/assets/generated-tiles/terrain-*.png` are deterministic raster caches produced from the original licensed tile PNGs and CFG files. They contain no new artistic material; they are derivatives of the above artwork and should be distributed with the same notices.
