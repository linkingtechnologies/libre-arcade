# Third-party notices

## Lan Master
Original game, source code, graphics and music by **Shiru**. The historical
source states that the game and source code are released into the **Public
Domain**.

The `/reference` directory preserves the certified historical ROM and derived
parity material used by the restoration. Original assets are retained for
software-preservation purposes; no AI-generated replacement assets are used.

## FamiTone v1.24
The original `famitone.asm` header identifies **FamiTone audio library v1.24**,
by Shiru (06/2011), and explicitly says the code may be considered **Public
Domain**.

`src/famitone.js` translates the subset of the published playback semantics
used by Lan Master. Music/SFX/DPCM payload bytes come from the certified
historical ROM.
