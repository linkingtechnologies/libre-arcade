# M10.3 — Bluetooth UI removal

The historical J2ME 1.0.5 release included Bluetooth multiplayer. The browser restoration keeps that fact in archaeology/reference documentation, but M10.3 removes Bluetooth from the public game interface.

Reasons:
- browser Bluetooth parity is not implemented;
- a dead menu entry looks like an unfinished feature;
- inventing a web multiplayer mode would be new development, not preservation.

Public main menu now contains only Solo Game, Options, Instructions, Credits, and Exit (with the Italian equivalents).

No gameplay-core code was changed.
