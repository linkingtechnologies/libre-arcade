# Changelog

## 1.0.0 — 2026-10-12

Initial Libre Arcade release of the MilCity browser restoration, based on **MilCity - Blue Edition 1.0.5 (2011)**.

- Faithful 1.0.5 gameplay/economy/combat core.
- Four historical AI levels: Easy, Medium, Hard and Madness.
- Modern bilingual browser UI with mouse/touch/keyboard support.
- Local autosave/resume.
- Procedural renderer informed by the historical visual audit; original PNG assets remain reference-only.
- Complete-match and parity test suite included.

Public release history intentionally starts here. Internal restoration milestones are preserved in the documentation for archaeological traceability, not as changelog entries.
