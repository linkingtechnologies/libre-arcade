## The license, and what kind of evidence we have

The upstream code is GPL version 2 **or, at the recipient's option, any later version**. This was checked directly in the preserved source when the game joined the collection: 16 of the 17 files in `src/` carry the header wording "either version 2, or (at your option) any later version", and the 17th (`src/files`) is a plain-text description of the source files, not code. `COPYING` is the GPL version 2 text. That "or later" grant is what allows the JavaScript port to be distributed as GPL-3.0-or-later, the same pattern used for Netris, Yanoid and Donkey Bolonkey. The independent audit (`specs/audit-phase2/LEGAL.md`) reached the same reading, and so did FreeBSD's `GPLv2+` classification quoted there.

## What was checked independently

- The "or later" header wording, in the preserved upstream source (above).
- The SHA-256 of the 24 preserved upstream files against `reference/ORIGINAL_FILE_MANIFEST.json`, and the absence of the 39 withheld files. This is now a permanent test (`tests/reference-integrity.mjs`).
- The delivered package's own checksum lists (177 and 47 entries) matched before any change.
- The delivered suite passed unchanged, and passes after the layout change: 816 physics scalars compared, 688 bit-identical, maximum absolute difference `7.1e-15` (up to 48 ULP where C++ `libm` and browser math differ, never tuned away).

## What was not re-verified

- **The live upstream site, and any later history.** The audit (17 September 2026) records 1.2.4 as the last upstream release, no version-control repository and no maintained successor. A direct fetch of the live site failed when the game was integrated (its HTTPS certificate has expired), so its present content is unchecked. "Effectively abandoned" and "no successor" are the audit's conclusions; the archived page below is consistent with them but is a snapshot, not proof of what came after.
- **The original archive.** The received TAR (686,080 bytes, SHA-256 `c0a4e71ce83323063df53104aaa46fb3488fa6712d2b7a4827cca48161494f0b`) and the private archive that contains it are not in this repository, so its hash was not checked again. The historical gzip wrapper (413,137 bytes, SHA-256 `4363ea2455869b886b5777272cddd69ac0a14c7635cdbdafba31eb1c6625bdc6`) was never received; its identity comes from FreeBSD metadata.
- **The native oracle.** A fresh native run needs the withheld original tree restored locally (the renderer stub reads GIF dimensions), a C++ toolchain and the build scripts in `reference/oracle/`. It was not rerun. The traces are used as frozen fixtures.
- **The sound lineage evidence** (below) is the audit's own research and was not repeated.

## Evidence supplied at integration: the archived upstream site

The collection's maintainer supplied a screenshot of `highmoon.gerdsmeier.net` as held by the Wayback Machine, the text of its news page, and screenshots of the original game (the version 1.2 title screen, the Russian and Portuguese interfaces and the in-game help). The archived page is not stored in this repository, and the capture date is not visible in the screenshot. What it shows:

- The footer reads "(c) 2005 - 2007 Patrick Gerdsmeier" with "Last Change 2007-8-6", which matches the audit's "official download page last changed 2007-08-06".
- The newest news item is "2006 March 25, HighMoon v1.2.4 - Added Support for Netherland Language". Two downloads are offered, both dated 2007-8-6: Linux `highmoon-1.2.4.tar.gz` (403 KB) and Windows `highmoon-1.2.4.zip` (848 KB), plus a link to the FreeBSD port. No later version is offered. The 403 KB is consistent with the 413,137-byte gzip size that FreeBSD records (about 403.5 KiB); that is a size match, not a hash check.
- The page says HighMoon is licensed under the GNU General Public Licence, without naming a version; the version wording comes from the source headers (above).
- The news text, compared line by line with `reference/reference/HighMoon/NEWS`, is identical except for the author's e-mail address, which the site writes in an anti-spam form (`patrickATgerdsmeierDOTnet`) where the archive has the plain address. Trailing whitespace was ignored in the comparison. This supports the preserved copy.
- The original's in-game help (in the supplied screenshot) lists the languages English, German, Polish, Portuguese, French, Spanish and Russian and the bonus colors (blue: shield +10, green: double-power laser, yellow: cluster laser, orange: shield +50). By the release notes Italian and Dutch came later, so the original ends with nine languages.

The screenshots of the original game show the withheld artwork, so they are not added to this repository (`REFERENCE_POLICY.md`). Limits: the snapshot cannot show what happened to the project after its capture, nor that no successor exists, and it was supplied rather than fetched.

## Why the original media stay out

The archive has no per-file credits or media license. The audit found that seven of the eight WAV files closely match the historical OpenOffice.org gallery sound family (same names and frame counts, several near-direct bit-depth conversions), that `curve.wav` and `laser.wav` carry an embedded RIFF creation date of 28 April 1995 (about ten years before HighMoon), and that `click.wav` is identifiable with QNetWalk's `connect.wav` from 2002. The bitmaps have no author information, and the planet and moon textures were flagged as the most doubtful. `specs/audit-phase8/ASSET_REVIEW.csv` lists every file with its status. An unknown status marks missing proof for this collection's standard, not a finding that a file is infringing. `REFERENCE_POLICY.md` has the full policy and the path to reopening it (file-specific permission or attributable provenance).

## What was not ported, and why

- **The original artwork and sounds**: see above; the browser build draws and synthesizes its own.
- **The vestigial "Exploding" weapon**: announced in 1.2, unreachable in 1.2.4 and falling back to the Cluster implementation; kept as the original behaves.
- **Compile-time-disabled paths** (trainer mode, thread mode): experimental and off in the release.
- **Cross-platform bit equality.** Reproducing the reference `libm` results bit for bit in a browser is not promised; the differences are measured and reported.
