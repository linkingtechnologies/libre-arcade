# Initial commit — HighMoon

- **Ready to commit as:** `1.0.0-rc.5` (first public browser-port commit, not final `1.0.0`).
- **Deployable directory:** `public/highmoon/`. No historical graphics or WAVs are included there.
- **Source preservation:** byte-identical HighMoon 1.2.4 source/docs and the upstream `NEWS` are under `reference/highmoon/reference/HighMoon/`; independent native oracle and archaeological research are under `reference/highmoon/oracle/` and `specs/highmoon/`.
- **Private archive:** keep the separately supplied full-original-TAR ZIP outside the public Git tree because of unresolved individual media provenance.
- **Local QA:** see `public/highmoon/docs/FINAL_QA_RC5.md`. Manual Firefox, Safari/iOS and live deployment checks remain to be performed before tagging `1.0.0`.
- **First-launch menu:** choose mode, read IT/EN instructions or Credits, then press Play; no simulation ticks before Play.
- **Audio:** Play emits a short confirmation after Web Audio unlock; the menu retains Audio On/Off, without a sound-test button. No historic WAVs or music were added.
- **Port changelog:** intentionally absent for the first commit. Upstream historical `NEWS` is preserved without modification.
