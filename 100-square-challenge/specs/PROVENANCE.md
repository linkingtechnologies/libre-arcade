# Provenance and release scope

All files in `reference/` were copied without modification from the original
user-supplied files in this conversation. The download URL of an individual
archive was not supplied, so these project pages are *context*, not claimed
verified binary download URLs:

- TAJJAVA: https://sourceforge.net/projects/tajjava/files/
- Later standalone project: https://sourceforge.net/projects/squarechallenge/

SHA-256 values of each included upstream file are in `SHA256SUMS.txt` at the
project root, with verification available via `sha256sum -c SHA256SUMS.txt`.

The earlier audit produced historical JAR screenshots, an oracle log, a
24-step blocked path, and a 100-cell completion witness; the browser test
suite consumes the same witness files copied to `test/fixtures/`.
