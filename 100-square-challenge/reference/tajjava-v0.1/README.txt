Project TAJJAVA Version 0.1 - README

Project TAJJAVA is a project to create multiple games in Java Swing as a single application.

Currently, the project is in a very early stage of development. This is the first release of the project so far. Only one game is complete and it is included in this release.

You need to have Java installed on your computer in order to use this software.
