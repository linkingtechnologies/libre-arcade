# reference/

The historical material behind this game is kept light and reproducible, not as a copy of the whole archive.

- `javagames-1.0/SOURCE.md` says where the archive comes from (SourceForge project "On-Line Java Games", file `javagames-1.0.tgz`), gives its size, date and SHA-256, and says what is kept and what is not.
- `javagames-1.0/ARCHIVE_SHA256.txt` lists all 63 files of the archive with their SHA-256.
- `javagames-1.0/xoworld.java`, `xoworld.html`, `README` and `COPYING` keep what is needed to document and run the game, unmodified (CRLF text, see the `.gitattributes` one level up).
- The compiled `xoworld.class`, the original images and the sources of the other applets of the suite (`tetris`, `pogodi`, `stomak`) are not redistributed: nothing establishes who drew the images or under which licence. The same rule is used for Bomber.

The full archive is not here on purpose: fetch it from the SourceForge file named in `SOURCE.md` and check it against `ARCHIVE_SHA256.txt`.
