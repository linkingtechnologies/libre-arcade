# XO World M8 — Release Candidate

M8 freezes the user-approved M7 gameplay and AI baseline and performs release-only hardening.

## Changes
- Release version set to `1.0.0-rc.1`.
- Native dialog Escape/cancel now closes Info and restores focus to the `?` control.
- Added release contract QA: clean `web/` payload, no development residue, no raster assets, Libre Arcade link and language/accessibility checks.
- No gameplay or AI changes.

## Release status
This package is a Libre Arcade release candidate. A final 1.0 can be cut after a last real-browser smoke test by the maintainer.
