# Changelog

## 1.0.0-rc.1

First Libre Arcade release candidate of the XO World restoration.

- Faithful 10×10 five-in-a-row gameplay.
- Historical CPU decision logic ported from the 2007 Java source.
- 22 deterministic behavioral oracle cases.
- Responsive Canvas UI with mouse, touch and keyboard support.
- English/Italian interface, help and credits.
- GPLv3 distribution with historical-source notices.
- Original raster assets are not redistributed.
