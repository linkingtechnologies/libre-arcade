# Original Ri-li audio

This directory preserves the historical Ri-li 2.0.1 audio files used as the restoration reference.

`menu.mod`, `jeu1.xm` and `jeu2.xm` are the authoritative tracker originals. The `/audio` directory contains OGG Vorbis derivatives solely for native browser playback. The WAV effects in `/audio` are byte-identical to the originals preserved here.

`COPYING.Music` is preserved beside the original music files.
