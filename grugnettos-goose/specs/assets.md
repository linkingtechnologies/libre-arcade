## Historical board artwork (v0.9)

The main board is now `Ganzenbord_pd.svg` by Pmathijssen from Wikimedia Commons, released into the public domain by its copyright holder. v0.9 currently loads the Commons-hosted original at runtime; the final offline package should vendor the exact verified SVG. The artwork is presentation only and does not define game rules.
