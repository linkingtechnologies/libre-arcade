# Provenance

Unlike every other "Ported" game in this collection, **Grugnetto's Goose is not a port of one historical program.** It is a new implementation of the traditional Game of the Goose, built through a documented software-archaeology workflow that studies historical artwork, traditional rules, and several earlier open-source digital implementations — while treating "studied" and "redistributable" as two separate questions. This table reflects that structure.

## On studying two games already in this collection

Two of the six studied-but-unbundled references — `rriesebos/game-of-the-goose` and `glParchis 20181125` — are the same upstream projects already restored elsewhere in this collection (`game-of-the-goose/`, `glparchis/`). This is coincidence, not circularity: Grugnetto's Goose studied their *original* upstream archives directly for architecture/UX comparison, the same way this collection's own restorations did, and bundled neither. The two restorations already in this collection and this one arrived at the same source material independently.

## Licensing: independently re-verified, not just re-stated

- Fetched `Ganzenbord_pd.svg` directly from `upload.wikimedia.org` (not from the bundled copy) and confirmed its SHA-1 (`2324f0f6...`) and SHA-256 both match the bundled file **exactly, byte-for-byte** — and confirmed on the live Commons page that Pmathijssen released it into the public domain in 2008.
- Confirmed on the live Commons page for `Ganzenbordspel.jpg` that Daan Hoeksema died in 1935 (making it public domain via PD-old-80) and that the original is 6,421×4,609 pixels — matching this project's own documentation exactly. The bundled 2048×1470 file's aspect ratio (1.39320) matches the Commons original's (1.39314) to four decimal places, and the image itself was opened and visually confirmed to be the genuine "Het aloude ganzenspel" lithograph, not a mismatched substitute.
- Confirmed all six "studied, not bundled" reference folders under `reference/` contain only a `PROVENANCE.md` note each — no quarantined archive, source dump, or asset is actually present, matching the project's own "admission policy" claim precisely. Read all six individually (`reference/*/PROVENANCE.md`) rather than just the summary tables; found `reference/QUARANTINE.md` — a real, accurate file restating the same six admission decisions — was not linked from `ARCHAEOLOGY.md`'s own documentation map or from `reference/README.md`, and fixed both. Also found and fixed a stale `public/assets/boards/README.md` left over from a pre-1.0 iteration, still describing a `local/` folder and a `ganzenbordspel-inspired.svg` placeholder that `test/release-contract.test.js` explicitly asserts no longer exist, and several `reference/*/PROVENANCE.md` files that still said `/src`/`/assets` instead of `public/src`/`public/assets` after the restructuring.
- Re-ran the project's own `npm test` (89 assertions across 79 tests, including `release-contract.test.js`'s reference-admission and no-Math.random/no-HTTP-dependency checks) after the `public/` restructuring — all pass unchanged.

## What was not ported, and why

- **The six studied software references** — none contributed code or assets; each has an unresolved license-version or asset-provenance gap documented in its own `reference/*/PROVENANCE.md`, and none is bundled.
- **Full-resolution `Ganzenbordspel.jpg` (6421×4609, 7.49MB)** — the runtime ships the smaller, explicitly-labeled-as-not-byte-identical 2048×1470 representation instead, to keep the package lightweight without misrepresenting it as the original scan.
- **Any third-party audio** — every WAV/Web-Audio cue is project-authored from scratch; no historical or third-party recording is used.
