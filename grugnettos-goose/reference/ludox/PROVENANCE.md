## Licence conclusion

SourceForge labels LudoX GPLv2, but neither examined source+executable archive contains `LICENSE`/`COPYING`, and the Java source headers contain only project/version/author comments—not GPL wording and not an “or later” clause.

Therefore **GPLv2-only vs GPLv2-or-later cannot be demonstrated from the original archives**. No LudoX code is used or derived in the GPLv3 Grugnetto’s Goose implementation.
