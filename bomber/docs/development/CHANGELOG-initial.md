# Changelog

## Initial Libre Arcade release

- Faithful HTML5/JavaScript reconstruction of the original one-button gameplay.
- English and Italian interface.
- Keyboard, mouse and touch controls.
- Responsive layout with no gameplay scrolling.
- Reconstructed Web Audio tones and timing behavior.
- Java-compatible deterministic random generator for QA.
- Separate Credits dialog with Libre Arcade link.
- Original historical release preserved unchanged in `reference/`.
- Historical PNG assets are not used by the public runtime pending separate provenance clearance.
