# Changelog

## 1.0.0

First release in Libre Arcade, built on the restoration package's "Initial Libre Arcade release".

- One-button Bomber: the plane, the 26-building city, the single bomb, the 141 ms turn, the difficulty growth and the three melodies, ported from the Java ME source. English and Italian interface, keyboard, mouse and touch input (with a DROP button), a credits dialog, an audio switch, a responsive layout with no scrolling during play.
- Preserved the original source under `reference/bomber-1.0/` (`GameCanvasBomber.java`, `Bomber.java`, the GPL text, the JAD and the manifest), with the archive's SHA-256, a checksum list for the preserved files and a manifest of the archive's 12 files. The two Java files are CRLF and are kept byte for byte (`.gitattributes`). The archive's PNG resources, jar and compiled classes are not redistributed.
- Added an executable oracle: the original loop is compiled unmodified with stand-ins for the MIDP classes and a `Thread` class that makes its sleeps virtual (`test/java-oracle/`), and the port is compared with it after every iteration. A recording of 750,000 iterations (1,540 games, 1,290 crashes, 93 landings, 37,474 bomb impacts) replays in `npm test` with every state, city, tone and wait identical; `npm run test:live` runs the original again. The port's random generator also reproduces `java.util.Random` for 7 seeds and every bound from 1 to 100.
- Ran the archive's own compiled class (18 December 2008) through the oracle too, by rewriting its `java.lang.Thread` reference in memory (`BOMBER_CLASS`, `redirectThread()` in `tools/java-oracle.mjs`): the same 750,000 iterations as the source build, and the port agrees after every one. The class itself is not redistributed. The `Graphics` stand-in's `drawImage` now returns `void`, as the binary's descriptor requires.
- Added the original's title credit lines ("ORIGINAL GAME BY JOSEPH DUFFY", "J2ME ADAPTATION BY JUAN J LUNA") to the title screen, translated into Italian for the Italian interface. The package's title screen did not show them.
- A press is now remembered until the next turn, so a tap shorter than a turn (141 ms) still drops a bomb. The original reads the key only while it is down and loses shorter presses, and the first version of the port did the same (12 to 16 of 25 presses of 30 ms registered in a browser test); now 25 of 25 key presses do, down to 5 ms, and so do 20 of 20 pointer presses of 15 ms on the canvas and on the DROP button. The held state is now also set before the audio context is awaited, so a key released while the context starts cannot stay "held" (a race that was possible in principle). A deliberate difference from the original, recorded in the port map; the game rules and the oracle are unchanged.
- Added `window.__bomber`, exposed only with `?qa=1` or `?seed=`, so that automated browser tests can read the game state.
- Joined the Libre Arcade collection: the files moved into `public/`, the single test became `test/parity.test.mjs`, and the collection scaffolding was added (`package.json` scripts, `scripts/serve.mjs`, `scripts/build.mjs`, an ESLint config, `.gitignore`, the GoatCounter snippet, the "Play here" link, the provenance, archaeology and port-map documents). The licence text is now the full GPL version 3.
- Checked in a real browser: start, keyboard bomb, crash and high score, landing and the taller next city, language, audio switch, credits dialog and a phone-sized layout, with no console errors.
- Kept the package's development notes and changelog unmodified in `docs/development/`.
