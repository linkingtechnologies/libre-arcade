# Credits

## Strider

The game itself, vendored with the changes listed in
[`../specs/design.md`](../specs/design.md).

- **By**: Petar Petrov ([kenamick](https://github.com/kenamick), KENAMICK Entertainment; the menu says "Dvubuz Games")
- **Source**: https://github.com/kenamick/strider (version 1.0.7, last commit 12 August 2022, archived by its owner on 9 April 2026)
- **License**: MIT, see [`LICENSE`](LICENSE) (the upstream file, unchanged)
- **Made for**: GitHub's Game Off 2015
- **Based on**: [Octocat Jump](https://github.com/ogoshen/game-off-2012) by Omer Goshen (Game Off 2012). Upstream's README keeps his copyright notice. **That repository carries no license at all**, so the MIT grant of Strider cannot extend to anything that is still Octocat Jump's. Comparing the two code bases, about 3% of Strider's significant lines in `game.js` (28 of 910) also appear in Octocat Jump, almost all of them Crafty boilerplate (viewport scrolling, key handling, text shadow); see `specs/design.md`.
