# Changelog

## 1.0.0 (2026-10-17)

- Vendored [kenamick/strider](https://github.com/kenamick/strider) 1.0.7
  into `public/`, restored and cleaned for standalone use. See
  [`specs/design.md`](specs/design.md) for every change and why, and
  [`public/CREDITS.md`](public/CREDITS.md) for authorship and the license of
  each asset.
- Replaced four sounds and the jump-dust sprite whose licenses could not be
  cleared (CC BY-NC, "Sampling", a deleted page, a dead site) with new ones
  generated by `tools/make-replacements.mjs`.
- Added dependency-free dev tooling (`npm run dev`/`build`/`start`/`test`/`lint`/`check`).
