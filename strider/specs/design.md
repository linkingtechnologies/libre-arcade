# Strider: design

This is a **restored** game (see the root `AGENTS.md`): upstream's own JavaScript, HTML and CSS, vendored and cleaned, with every change listed below. No `reference/` folder, no port map.

## What upstream is

[kenamick/strider](https://github.com/kenamick/strider), version 1.0.7, 203 commits from 26 March 2015 to 12 August 2022, archived (read-only) by its owner on 9 April 2026. A 400 by 640 vertical climber on the Crafty 0.6.3 engine: double jump, an auto-aiming rifle, health and energy pickups, drones, turrets, spikes, an exit ship at the top. Built with Grunt and Bower, shipped as a Chrome app, an NW.js desktop build, and a Game Jolt / itch.io page.

## Structure here

```
public/
  index.html        upstream's, rewritten (see below)
  js/               upstream's src/traps.js, loader.js, menu.js, game.js, plus fit.js (new)
  lib/crafty.js     upstream's lib/crafty.js (0.6.3), untouched
  css/main.css
  assets/           images/, sfx/, fonts/ (a subset of upstream's assets/)
  CREDITS.md, LICENSE
```

Upstream's Grunt build concatenated `src/traps.js`, `loader.js`, `menu.js` and `game.js` (separator `;`) into `game.js` and uglified it. Here `index.html` loads the four files in the same order as separate classic scripts, so there is no build step beyond `npm run build` copying `public/` to `game/`. They share the global scope exactly as the concatenation did.

## Changes from upstream

| What | Why |
|---|---|
| `index.html` rewritten: plain `<script>` tags (Crafty, upstream's four files, then `fit.js`) instead of Grunt `build:` comments, GoatCounter snippet added | No Grunt, no Bower, no `processhtml`; collection analytics |
| `js/menu.js`: `"@@VERSION"` replaced by `"1.0.7"` | Grunt's `replace` task did this at build time |
| `js/menu.js`, `js/loader.js`: the intro no longer shows the GitHub Game Off logo; `assets/images/gameoff.jpg` is not shipped and is dropped from the loader list | A GitHub-owned logo with no license to rely on; the intro now opens on the Crafty logo |
| `js/loader.js`: four audio entries point to `.wav` replacements | See "Replaced assets" |
| `css/main.css`: `#game` gets `transform: translate(-50%, 0%) scale(var(--fit, 1))` with `transform-origin: 50% 0`; new `js/fit.js` sets `--fit` to `min(1, window.innerHeight / 642)` and replaces `Crafty.domHelper.translate` | The stage is a fixed 640 px tall; in a browser window shorter than that (a laptop with a toolbar) upstream clipped the bottom, hiding the version number, the spikes and the sound icons. It now scales down to fit. Crafty 0.6.3 turns mouse positions into stage positions from an offset measured once at startup and ignores CSS transforms, so `fit.js` swaps in a `translate()` that measures the stage at each event and divides by the same factor (`lib/crafty.js` is not edited). Tried first: letting the page scroll, which showed a scrollbar over the game |
| `css/main.css`: unused `bmspa` `@font-face` removed; `assets/fonts/bmspa.ttf` not shipped | No code uses the font (searched `src/` and `index.html`), and its license is unknown |
| `assets/images/smoke_jump.png` replaced | See "Replaced assets" |
| Not shipped: `lib/gj-js-api*.js`, `assets/troph/`, `assets/crx/`, `assets/desktop/`, `lib/crafty-min.js`, `Gruntfile.js`, `manifest.json`, `strider.in`, `package.json`, `src/chrome.js`, `src/header.txt` | Game Jolt client and trophy art (a hosted score service we do not use), Chrome app, desktop and packaging files, and a minified duplicate of Crafty |

**Game Jolt is dead code, not removed code.** `js/traps.js` (upstream's own) sets `window.GJAPI = {}`, so every `GJAPI.bActive` check in the game and the menu is false and the trophy and high-score calls never run. No network request to Game Jolt is made. The calls stay in `game.js` and `menu.js` untouched; shipping the Game Jolt library would only add a remote client.

**Safari audio.** Upstream disables sound under Safari because Crafty could not play `.m4a` there, and shows a notice. That is unchanged. The `.m4a` copies of the kept sounds are shipped for the same reason upstream shipped them; the four replacement sounds are `.wav` only.

## Replaced assets

Five assets were replaced by new ones generated by `tools/make-replacements.mjs` (deterministic, dependency-free, MIT):

- `doorshut`, `liftoff`: upstream's sources are CC BY-NC 4.0 on Freesound. "NonCommercial" is not compatible with a collection whose point is free redistribution.
- `deathsplat`: upstream's source is under the Creative Commons "Sampling" license, which is not a free license.
- `landfeet`: the Freesound page named in upstream's credits no longer exists, so no license could be read.
- `smoke_jump.png`: upstream (and Octocat Jump before it) credits Pow Studio's "Smoke Animation Pack 1". The site now serves a parked page and the Internet Archive was not reachable from this environment, so the license could not be read.

The replacements are plain: a thump and a clang for the door, a rising noise sweep for the lift off, a short wet burst for the splat, a soft thud for the landing, and ten frames of grey puffs for the dust. They are not the original sounds and they do not try to be. If someone later finds a clear license for any original, restoring it means dropping the file into `assets/sfx/` and pointing `loader.js` back at it.

The mapping from file to source was read from upstream's git history; see `public/CREDITS.md`.

## Octocat Jump

Strider says in its header and README that it is a fork of Omer Goshen's Octocat Jump (GitHub Game Off 2012). That repository has no license file and the GitHub API reports none, only a copyright line in the README. Upstream relicensed Strider as MIT (commit "Update license info. MIT should be Ok ..." on 4 April 2015) with a note that the original is Omer Goshen's copyright.

Measured here: after trimming blanks and comments, 28 of 910 lines of `game.js`, 19 of 214 of `menu.js` and 7 of 119 of `loader.js` also occur verbatim in `octocatjump.js`. They are viewport scrolling, key handling and Crafty entity boilerplate. Strider's own mechanics (guns, enemies, energy, levels) are not in Octocat Jump at all. This is a residual risk, not a resolved one: nothing here shows that the author of Octocat Jump agreed to any license. It is stated in `public/CREDITS.md` and in the root `README.md`.

## Verification

Level 3 of the collection's hierarchy, and a light one: no oracle exists for a game this loosely specified. What was checked:

- `npm test`: the page loads the scripts in order, every image and sound the loader names exists, nothing from Game Jolt is shipped, the removed assets are really gone, and the credits name every replaced source.
- In a browser (Chromium, local server): the loading scene finishes, the intro and menu appear, "Play" starts the game, jumping and moving work, and the console shows no errors. The sound effects were not listened to; only that all 31 audio entries load, including the four `.wav` files.
- Window shorter than the stage (800 by 450): the whole game is visible, and clicking the sound icon toggles it (checked in the sound state, not by ear); at 800 by 700 the same click also works.
- Not checked: Firefox, Safari, touch input (upstream has none), the end of the climb, the Game Jolt-free score screen.
